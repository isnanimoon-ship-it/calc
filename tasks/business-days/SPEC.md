# SPEC: 영업일 계산기

## 목적

사용자가 대한민국 달력 기준으로 두 날짜 사이의 영업일 수를 계산하거나, 기준일에서 지정한
영업일 수만큼 전·후의 날짜를 찾을 수 있게 한다. 주말뿐 아니라 법정공휴일, 대체공휴일,
임시공휴일과 임기만료 선거일을 가능한 범위에서 정확하게 제외하고, 어떤 날짜가 어떤 이유로
제외됐는지 상세 내역을 제공한다.

`영업일`은 모든 조직에서 동일하지 않다. 계산기는 기본적으로 일반적인 월~금 근무와 대한민국
공휴일을 기준으로 하되, 사용자가 토요일·일요일·공휴일·근로자의 날 및 직접 지정한 휴무일의
제외 여부를 조절할 수 있게 한다. 은행 결제일, 법원의 기간 계산, 행정기관 민원 처리기한처럼
별도 법령이나 업무 규칙이 있는 사례의 최종 판단을 대신하지 않는다.

## 주요 사용자

- 프로젝트·계약·납품 일정을 영업일 기준으로 계산하려는 직장인
- 특정 날짜부터 N영업일 뒤의 처리 예정일을 확인하려는 사용자
- 휴가·출장·업무 일정을 계획하는 개인과 소규모 사업자
- 공휴일과 대체공휴일이 포함된 기간의 실제 근무일을 확인하려는 사용자

## 핵심 사용자 흐름

### 모드 A: 기간 내 영업일 계산

1. `기간 계산` 모드를 선택한다.
2. 시작일과 종료일을 입력한다.
3. 시작일과 종료일을 계산에 포함할지 선택한다.
4. 주말·공휴일 등 제외 규칙을 확인하거나 변경한다.
5. 계산 버튼을 누른다.
6. 전체 대상 일수, 영업일 수, 제외된 주말·공휴일 수를 확인한다.
7. 제외된 날짜 목록에서 날짜별 제외 사유를 확인한다.

### 모드 B: N영업일 전·후 날짜 계산

1. `영업일 더하기/빼기` 모드를 선택한다.
2. 기준일과 영업일 수를 입력한다.
3. 이전 또는 이후 방향과 기준일 포함 여부를 선택한다.
4. 제외 규칙을 확인하고 계산한다.
5. 도착 날짜와 계산 도중 건너뛴 주말·공휴일을 확인한다.

## Must Have

### 계산 모드

- **기간 계산**과 **영업일 전·후 계산**을 명확히 분리한다.
- 모드를 전환하면 해당 모드에 필요한 입력만 표시한다.
- 모드 전환 후 이전 결과를 남겨 서로 다른 계산 결과를 혼동시키지 않는다.

### 기간 계산 입력

- 시작일과 종료일은 필수다.
- 종료일은 시작일보다 빠를 수 없다.
- 시작일 포함 여부와 종료일 포함 여부를 각각 선택할 수 있다.
- 기본값은 양 끝 날짜 모두 포함이다.

### 영업일 전·후 계산 입력

- 기준일과 영업일 수는 필수다.
- 방향은 `N영업일 후`와 `N영업일 전` 중 하나를 선택한다.
- 영업일 수는 0 이상의 정수이며 상한은 Formula 단계에서 성능과 지원 데이터 범위를 고려해
  확정한다.
- 기준일이 영업일인 경우 기준일을 1일차로 포함할지 선택한다. 기본값은 미포함이다.
- 0영업일 입력 시 기준일을 반환하되, 기준일이 휴일이면 어떤 정책을 적용할지 Formula에서
  명시한다.

### 영업일 제외 규칙

다음 항목을 각각 켜고 끌 수 있어야 한다.

- 토요일 제외: 기본 ON
- 일요일 제외: 기본 ON
- 대한민국 공휴일 제외: 기본 ON
- 대체공휴일 제외: 공휴일 제외에 연동, 기본 ON
- 임시공휴일·임기만료 선거일 제외: 공식 데이터에 확정된 경우 기본 ON
- 근로자의 날 제외: 기본 ON으로 제안하되, 조직별 차이가 있음을 인접 안내로 표시
- 사용자 지정 휴무일 제외: 선택 입력

대체공휴일은 원래 공휴일을 다른 날로 옮기는 것이 아니라 원래 공휴일과 대체공휴일이 각각
공휴일이라는 원칙으로 처리한다. 같은 날짜에 주말과 공휴일 등 여러 제외 사유가 겹쳐도 날짜는
한 번만 제외하되 모든 사유를 상세 내역에 보존한다.

### 사용자 지정 휴무일

- 사용자가 날짜와 선택적 메모를 여러 건 추가·삭제할 수 있다.
- 공식 공휴일과 중복되어도 중복 차감하지 않는다.
- v1에서는 브라우저 세션 밖으로 자동 저장하지 않는다.
- 사용자 지정 영업일(공휴일이지만 근무하는 날) 기능은 Should Have로 둔다.

### 핵심 결과

기간 계산 결과에는 다음 값을 표시한다.

- **영업일 수**: 가장 큰 핵심 결과
- 계산 대상 전체 일수
- 제외된 총 날짜 수
- 토요일 수와 일요일 수
- 공휴일·대체공휴일·임시공휴일·선거일 수
- 사용자 지정 휴무일 수

영업일 전·후 계산 결과에는 다음 값을 표시한다.

- **도착 날짜**: 가장 큰 핵심 결과
- 입력한 영업일 수와 계산 방향
- 실제로 탐색한 전체 달력 일수
- 건너뛴 날짜 수와 유형별 합계

### 상세 내역

- 제외된 날짜를 날짜순으로 표시한다.
- 각 행에 요일, 공휴일명 또는 제외 사유, 분류를 표시한다.
- `광복절 · 일요일`처럼 사유가 겹친 경우 모든 사유를 보여준다.
- 항목이 많은 경우 초기에는 요약하고 펼쳐볼 수 있게 한다.
- 결과 합계와 상세 날짜 수가 항상 일치해야 한다.
- 계산에 포함된 공식 공휴일 데이터의 확인 범위와 마지막 갱신일을 표시한다.

### 계산 방법 안내

- 시작·종료일 포함 여부를 실제 입력값과 함께 표시한다.
- 적용된 제외 규칙을 나열한다.
- `대상 날짜 − 제외 날짜 = 영업일` 계산을 실제 수치로 보여준다.
- 전·후 계산에서는 기준일부터 영업일만 세어 도착일까지 이동한 과정을 설명한다.
- 날짜는 Asia/Seoul 달력 기준이며 시각·시간대는 계산하지 않는다고 안내한다.

### 공휴일 정확성

- 한국천문연구원 `특일 정보`의 공휴일 데이터 스냅샷을 공식 기본 데이터로 사용한다.
- 대체공휴일 규칙 엔진을 별도로 구현하고 공식 데이터와 교차 검증한다.
- 음력 공휴일 날짜를 애플리케이션에서 독자적으로 천문 계산하지 않는다.
- 임시공휴일과 선거일은 정부 발표 후 공식 데이터 또는 검증된 예외 데이터에 반영한다.
- 아직 발표되지 않은 미래 임시공휴일을 추정하지 않는다.
- 지원 연도와 데이터 확정 상태를 사용자에게 표시한다.
- 공식 데이터와 규칙 엔진 결과가 불일치하면 해당 연도의 배포 검증을 실패 처리한다.

### 오류와 예외

- 날짜 누락, 존재하지 않는 날짜, 역전된 기간은 필드 가까이에 오류를 표시한다.
- 지원 연도 밖의 날짜는 계산하지 않고 지원 범위를 안내한다.
- 제외 규칙을 모두 끈 경우 계산은 허용하되 단순 달력 일수임을 표시한다.
- 모든 날짜가 제외되어 영업일이 0일인 기간을 정상 결과로 처리한다.
- 사용자 지정 휴무일의 중복과 범위 밖 날짜를 안전하게 처리한다.
- 윤년, 월말, 연말·연초, 장기 연휴와 대체공휴일 연쇄를 처리한다.

### 개인정보·오프라인 동작

- 입력 날짜와 사용자 지정 휴무일은 서버로 전송하거나 저장하지 않는다.
- 계산 중 외부 공휴일 API를 브라우저에서 호출하지 않는다.
- 검증된 공휴일 스냅샷을 애플리케이션과 함께 배포해 계산은 클라이언트에서 완결한다.

### 접근성·반응형

- 모드와 계산 방향은 실제 라디오 그룹으로 구현한다.
- 제외 규칙은 실제 체크박스를 사용한다.
- 모든 날짜·숫자 입력에 label, 도움말, 오류 연결을 제공한다.
- 결과 영역은 `aria-live="polite"`로 갱신을 알린다.
- 색상만으로 영업일과 제외일을 구분하지 않는다.
- 상세 내역은 모바일에서 가로 스크롤에 의존하지 않는 목록 또는 반응형 표로 제공한다.
- 320px, 375px, 390px, 768px, 1440px에서 페이지 전체 가로 스크롤이 없어야 한다.

### 공통 제품 요건

- 계산하기, 샘플 값, 초기화 기능을 제공한다.
- 입력 변경 후 이전 결과를 제거하거나 이전 입력 기준임을 명확히 표시한다.
- 결과 순서는 핵심 결과 → 유형별 요약 → 제외 날짜 상세 → 계산 방법 → 데이터 기준 → FAQ로 한다.
- 소개, 사용 방법, FAQ와 `WebApplication`·`FAQPage` 구조화 데이터를 제공한다.
- 계산 로직과 공휴일 판정 로직은 UI에서 분리한 순수 함수로 구현한다.
- Golden Test 3개 이상, 전체 날짜·정책 테스트 20개 이상을 작성한다.

- 공휴일이지만 실제로 근무하는 `사용자 지정 영업일` 추가
- 월~금 외 사용자 지정 근무 요일 설정
- 제외 날짜 목록 CSV 다운로드
- 결과 텍스트 복사 및 조건을 포함한 URL 공유
- 월별 영업일 요약
- 공휴일 데이터 갱신 상태를 관리자 또는 빌드 로그에서 확인하는 검증 도구
- 관공서 기준과 일반 사업장 기준 프리셋

## Could Have

- 여러 국가의 공휴일 캘린더 선택
- 회사 휴무일 캘린더 파일(ICS) 업로드
- 반복 휴무 규칙
- 영업시간과 마감 시각까지 고려한 SLA 계산
- 결과 캘린더·ICS 다운로드
- 은행 영업일 또는 증권시장 거래일 전용 모드

## v1 범위 밖

- 법원의 소송기간, 행정심판·민원 처리기간 등 개별 법령상 기간의 최종 법률 판단
- 은행별 결제·이체 처리일과 한국거래소 휴장일 자동 판정
- 회사별 취업규칙·단체협약에 따른 유급휴일 자격 판정
- 아직 정부가 발표하지 않은 임시공휴일 예측
- 시간·분 단위 영업시간과 해외 시간대 계산

## 정책 및 데이터 기준

- `공휴일에 관한 법률`과 `관공서의 공휴일에 관한 규정`의 시행일별 버전을 관리한다.
- 법령 개정으로 공휴일 또는 대체공휴일 대상이 바뀌면 과거 연도 결과가 바뀌지 않도록 정책을
  유효기간별로 저장한다.
- 근로자의 날은 공휴일 법령과 근로기준법 적용 범위가 변경될 수 있으므로 독립 분류로 관리한다.
- 공휴일 데이터는 `holiday-data/{year}.json` 형태의 연도별 스냅샷으로 관리한다.
- 각 스냅샷에 출처, 조회일, 데이터 해시, 확정·잠정 상태를 기록한다.
- 임시공휴일·선거일 예외는 근거 URL과 발표일이 없는 상태로 추가할 수 없다.

## 성공 지표

- 공휴일이 포함된 대표 기간 계산에서 공식 달력과 일치
- 대체공휴일·임시공휴일·선거일 누락 0건
- 중복 제외로 인한 합계 오류 0건
- 사용자가 결과 상세에서 제외된 이유를 확인할 수 있음
- 정책 지원 범위 밖의 날짜를 잘못 계산하지 않음

## 완료 기준

- 지원하는 전체 연도의 공휴일 스냅샷이 공식 데이터와 검증된다.
- 대체공휴일 규칙 엔진과 공식 스냅샷의 차이가 0건이다.
- 포함·미포함, 전·후 방향, 0영업일과 경계값이 FORMULA와 테스트에서 일치한다.
- 계산 정확성 감사 33/35 이상, 총점 92점 이상이며 Critical·High 결함이 없어야 공개한다.
