# HOLIDAY DATA: 영업일 계산기

## 목적

대체공휴일과 임시공휴일까지 정확하게 계산하기 위한 데이터 수집·검증·배포 원칙을 정의한다.
이 문서는 제품 범위를 정하는 SPEC을 보완하며, 구체적인 날짜 공식은 다음 단계의 FORMULA에서
확정한다.

## 데이터 계층

### 1. 공식 스냅샷

- 출처: 한국천문연구원 특일 정보 OpenAPI
- 사용 필드: 날짜, 명칭, 공휴일 여부, 순번
- 역할: 국경일, 명절, 대체공휴일과 공개된 임시공휴일의 기본 SSOT
- 브라우저에서 실시간 호출하지 않고 연도별 정적 JSON으로 변환한다.

### 2. 법령 규칙 엔진

- 출처: 공휴일에 관한 법률, 관공서의 공휴일에 관한 규정
- 역할: 고정일 공휴일과 대체공휴일 규칙을 시행일별로 재현한다.
- 공식 스냅샷을 대체하기보다 누락·오류를 탐지하는 교차 검증 수단으로 사용한다.
- 설날·추석·부처님오신날의 음력→양력 변환은 직접 구현하지 않는다.

### 3. 검증된 예외 데이터

- 대상: 임시공휴일, 임기만료 선거일, 공식 API 반영 지연 수정
- 필수 메타데이터: 날짜, 명칭, 분류, 정부·선관위 근거 URL, 발표일, 검토일
- 근거 없는 수동 항목은 빌드 데이터에 포함할 수 없다.

### 4. 사용자 데이터

- 사용자 지정 휴무일과 사용자 지정 영업일
- 공식 데이터와 별도로 유지하고 계산 마지막 단계에 적용한다.
- 공식 공휴일과 중복되어도 날짜는 한 번만 제외한다.

## 제안 파일 구조

```text
src/data/holidays/
  manifest.json
  2025.json
  2026.json
  2027.json
  exceptions.json

scripts/holidays/
  fetch-official.mjs
  normalize.mjs
  verify.mjs
```

## 스냅샷 예시

```json
{
  "year": 2026,
  "status": "confirmed",
  "source": "KASI special-day OpenAPI",
  "fetchedAt": "YYYY-MM-DD",
  "reviewedAt": "YYYY-MM-DD",
  "holidays": [
    {
      "date": "2026-01-01",
      "name": "1월1일",
      "kind": "public-holiday",
      "isHoliday": true
    }
  ]
}
```

## 정규화 규칙

- 날짜 키는 `YYYY-MM-DD`로 통일한다.
- 같은 날짜의 여러 명칭을 하나의 날짜 레코드 안에 배열로 보존한다.
- 공휴일명 문자열만으로 대체공휴일 여부를 결정하지 않는다.
- 날짜별 분류는 `public-holiday`, `substitute-holiday`, `temporary-holiday`, `election-day`,
  `labor-day` 중 하나 이상을 가질 수 있다.
- 토요일·일요일 여부는 데이터에 저장하지 않고 날짜 함수로 판정한다.

## 빌드 검증

1. JSON 스키마와 날짜 유효성을 검사한다.
2. 같은 날짜의 중복 레코드를 병합했는지 검사한다.
3. 법령 규칙 엔진이 생성한 대체공휴일과 공식 스냅샷을 비교한다.
4. 예외 데이터의 근거 URL·발표일·검토일 존재 여부를 검사한다.
5. manifest의 지원 연도와 실제 파일이 일치하는지 검사한다.
6. 불일치가 있으면 계산기 배포를 중단하고 사람이 원인을 확인한다.

## 런타임 원칙

- 계산은 정적 스냅샷만 읽어 클라이언트에서 수행한다.
- 공공데이터 API 장애나 인증키 만료가 사용자 계산을 중단시키지 않아야 한다.
- 지원 연도 밖 날짜는 규칙만으로 추정 계산하지 않는다.
- 화면에 사용한 데이터 연도, 확정 상태와 마지막 검토일을 표시한다.

## 갱신 운영

- 정기 갱신: 다음 연도 데이터가 공개된 시점과 매년 1월
- 수시 갱신: 임시공휴일 발표, 선거일 확정, 공휴일 관련 법령 개정
- 갱신 후 Golden Test와 전체 회귀 테스트를 실행한다.
- 과거 스냅샷은 덮어쓰기보다 변경 이력과 근거를 남긴다.

## 공식 출처

- 공공데이터포털 `한국천문연구원_특일 정보`
- 국가법령정보센터 `공휴일에 관한 법률`
- 국가법령정보센터 `관공서의 공휴일에 관한 규정`
- 임기만료 선거일은 중앙선거관리위원회 공식 일정
- 임시공휴일은 정부 공식 발표 또는 관보
