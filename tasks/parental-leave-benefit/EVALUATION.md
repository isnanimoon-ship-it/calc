### 자체 검토 질문

1. 처음 온 사용자가 일반·부모 함께·한부모의 차이를 알 수 있는가? — 유형 설명과 조건부 입력으로 구분된다.
2. 가장 먼저 필요한 입력이 드러나는가? — 시작일, 기간, 통상임금이 기본 2열 영역에 모여 있다.
3. 부모 함께 선택 시 필요한 정보만 나타나는가? — 자녀·배우자 입력이 조건부로 표시된다.
4. 12개월 초과의 추가 요건을 놓치지 않는가? — 13개월부터 별도 경고 표면에 표시된다.
5. 결과에서 총액을 즉시 찾을 수 있는가? — 저채도 강조 카드의 가장 큰 숫자로 표시된다.
6. 총액의 근거를 추적할 수 있는가? — 월별 정책·지급률·상한·예상액을 제공한다.
7. 배우자 예정 사용을 확정액으로 오해하지 않는가? — 결과 카드에 조건부 경고를 표시한다.
8. 모바일에서 월별 표를 사용할 수 있는가? — 640px 미만에서는 카드 목록으로 전환한다.
9. 색상을 보지 않고 상태와 의미를 이해할 수 있는가? — 모든 상태를 텍스트로 함께 표시한다.
10. 지원하지 않는 부분월을 숨기지 않는가? — 입력 카드와 FAQ에 제한을 반복 안내한다.

- 다크 모드 경고색 토큰을 디자인 시스템의 warning surface/border와 연결했다.
- 핵심 결과 → 계산 요약 → 월별 내역 → 계산 방법 → 자격 안내 순서가 자연스럽다.
- 긴 18개월 내역은 모바일 카드로 분리돼 페이지 전체 가로 스크롤을 만들지 않는다.
