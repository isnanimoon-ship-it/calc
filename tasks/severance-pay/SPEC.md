# SPEC: 퇴직금 계산기

## 목적
퇴직을 앞두었거나 이미 퇴직한 일반 근로자가, 법령(근로자퇴직급여 보장법·근로기준법)에 근거한 법정 퇴직금 예상액과 그 산출 근거를 별도의 노무 지식 없이 스스로 확인할 수 있게 한다. "내가 얼마나 받는지"뿐 아니라 "왜 그 금액인지"까지 이해시키는 것을 목표로 한다.

## Must Have
- **지급요건 사전 체크 (v2 갱신: 주 소정근로시간 입력을 필수 → 선택으로 전환)**: 계속근로기간 1년 이상, 4주 평균 주 소정근로시간 15시간 이상 두 요건으로 지급 대상 여부를 판정한다.
  - 계속근로기간 1년 이상 요건은 입사일·퇴사일로부터 자동 산출하며 계속 필수 입력이다.
  - 주 소정근로시간 요건은 **기본값을 "충족(15시간 이상)으로 간주"로 두고 입력을 선택(생략 가능)으로 전환**한다. 대다수 정규 근로자는 자명하게 15시간 이상 근무하므로 매 계산마다 입력을 요구하지 않는다.
  - 단, 실제로 주 15시간 미만인 초단시간 근로자가 스스로 정정할 수 있도록 "주 15시간 미만 근로자입니다" 등 체크박스(또는 이에 준하는 명시적 토글)를 제공하고, 사용자가 이를 선택하면 지급요건 미충족으로 판정해 "지급대상 아님" 안내를 표시한다.
  - 근거: 퇴직급여보장법 제4조는 실제 지급요건이므로 요건 자체를 제거해서는 안 되며, 이번 변경은 "기본값 처리 방식"만 바꾼다 — 요건 판정 로직·문구는 그대로 유지한다.
  - 계속근로기간 1년 미만이거나, 사용자가 주 15시간 미만을 직접 표시한 경우, 금액 대신 "지급대상 아님" 안내만 표시하고 계산을 진행하지 않는다.
- **재직일수 계산**: 입사일·퇴사일 입력으로 재직일수를 자동 산출한다.
- **평균임금 산출 (간편 모드, 직접 입력 방식)**: 퇴사일 이전 3개월간 지급된 임금총액을 사용자가 한 번에 직접 입력하는 방식(고용노동부 예시 기준의 A안)만 v1에 포함한다. 월별 항목을 나눠 입력받아 자동 합산하는 방식은 포함하지 않는다.
- **상여금·연차수당 가산 입력(선택 입력)**: 퇴사일 이전 12개월 상여금 총액, 연차수당 총액을 선택 입력으로 받아 평균임금에 가산할 수 있게 한다. 미입력 시 0원으로 처리.
- **통상임금 비교 입력(선택 입력)**: 1일 통상임금을 선택 입력으로 받아, 산출된 평균임금과 비교해 더 큰 값을 최종 계산에 사용할 수 있게 한다. 미입력 시 평균임금만 사용.
- **결과 화면 breakdown**: docs/DESIGN_SYSTEM.md의 공통 화면 순서(입력 → 결과 → 계산 근거 → 정책 안내)를 따라, 핵심 결과 금액과 함께 평균임금 산출 과정·기준임금 결정 과정을 단계별 수식과 근거 법령 라벨을 붙여 노출한다.
- **정책 고지 문구**: 결과 화면 하단에 근거 법령명과 "실제 지급액과 차이가 있을 수 있다"는 고지 문구를 표시한다.
- **입력 오류/극단값 방어**: 퇴사일이 입사일보다 빠른 경우, 필수값 미입력, 음수 입력 등 잘못된 입력에 대해 계산을 진행하지 않고 오류 안내를 표시한다.
- **결과 화면 카피 톤 (v2 신규)**: 결과 표시 문구는 "계산이 진행되었습니다" 류의 수동적·서비스 대행 어투를 피하고, "계산을 진행합니다" 같은 확정적·직접적인 어투를 사용한다. 이는 카피 가이드라인이며, 구체적 문구·표현은 Builder 재량으로 정한다.
- **"사용 안내" 섹션 (v2 신규)**: docs/ARCHITECTURE.md "SEO/사이트맵" 페이지 구조(계산기 → 결과 → 사용 방법 → 공식 → 예제 → FAQ)의 "사용 방법" 단계에 해당하는 섹션을 추가한다. 계산기를 처음 보는 사용자가 어떤 값을 어떻게 입력하면 되는지 짧게 설명한다(예: "입사일과 퇴사일을 입력하면 재직일수를 자동 계산합니다", "3개월 임금총액만 입력해도 계산할 수 있으며, 상여금·연차수당·통상임금은 있는 경우에만 추가로 입력하세요" 등). 구체적 문구는 Builder 재량이되, 위 지급요건 선택 입력 변경(주 소정근로시간 기본값 처리)도 사용 안내에 반영되어야 한다.
- **소개 콘텐츠 + FAQ 섹션 (v2 신규)**: "퇴직금 계산기란 무엇인가요?" 류의 짧은 소개 콘텐츠(이 계산기가 무엇을 계산해주는지, 어떤 사용자에게 유용한지)와 FAQ 섹션을 추가한다. docs/ARCHITECTURE.md 페이지 구조의 "예제/FAQ" 단계에 해당한다.
  - FAQ에 포함되어야 할 질문 목록(질문만 정의, 답변 내용은 정의하지 않음 — 새로운 법적 주장이므로 Formula Analyst가 근거를 확인한 뒤 작성):
    1. 1년 미만 근로 후 퇴직하면 퇴직금을 받을 수 없나요? (지급요건 관련, 계산기 로직과 직결)
    2. 퇴직금 지연 지급 시 이자는 어떻게 되나요? (계산기가 직접 계산하는 값은 아니므로 정보성 안내로만 작성 — 법령 근거는 Formula Analyst가 확인)
    3. 상여금이나 성과급도 퇴직금 산정 기준에 포함되나요? (계산기의 상여금 가산 입력과 직결)
    4. 평균임금에 포함되는 항목은 무엇인가요? (계산기의 평균임금 산출 로직과 직결)
    5. 퇴직금 세금은 얼마인가요? — **이 계산기 범위 밖(퇴직소득세는 별도 계산기 영역)이므로, 구체적 세액을 계산/제시하지 않는다. 답변은 "이 계산기는 세전 법정 퇴직금만 계산하며, 퇴직소득세는 별도 계산기 영역에서 다룰 예정"이라는 안내로 대체한다.** 질문 자체는 실제 사용자 검색 의도와 일치하므로 FAQ 목록에서 제외하지 않고 남겨 두되, 답변 범위를 위와 같이 한정한다.
  - 위 질문 중 1·3·4번은 이미 SPEC의 Must Have 계산 로직(지급요건, 상여금 가산, 평균임금 산출)에 대응하는 근거 확인이므로 Formula Analyst가 FORMULA.md 작성 시 근거를 이미 확인했을 가능성이 높다 — 중복 조사를 피하고 기존 FORMULA.md 근거를 우선 재사용한다. 2번(지연이자)은 FORMULA.md에 아직 없는 새 주제이므로 Formula Analyst의 추가 확인이 필요하다.
- **디자인: 카드/시각적 계층 (v2 신규)**: "사용 안내"와 "계산 근거"(평균임금 산출 과정 등) 섹션은 텍스트를 단순 나열하지 않고, 카드 구분·아이콘·단계 표시 등으로 시각적 계층을 갖춘다. 구체적 디자인(레이아웃, 컴포넌트 선택)은 Architect/Builder 재량이며, docs/DESIGN_SYSTEM.md 기준을 따른다.

## Should Have
- **상세 모드**: 3개월 임금총액을 월별 기본급 + 기타수당으로 나눠 입력받아 자동 합산하는 모드(고용노동부 공식 계산기 방식). 간편 모드로도 목적 달성이 가능하므로 v1에서는 제외하고, 이용 빈도·요청에 따라 v2에서 추가 검토한다.
- **평균임금 산정 제외기간 입력**: 수습(입사 후 3개월 이내), 사용자 귀책 휴업, 출산전후휴가, 업무상 재해 휴업, 육아휴직 등 특정 기간을 산정기간·임금에서 제외하는 입력. 해당 사유가 있는 사용자에게는 결과 정확도에 큰 영향을 주지만, 대다수 일반 사용자에게는 해당하지 않는 예외 케이스이므로 v1 이후로 미룬다.

## Could Have (v1 범위 제외)
- 퇴직소득세 계산 연동 (별도 세금 계산기 영역의 몫)
- DC형/DB형 퇴직연금 비교 계산
- 중간정산 퇴직금 계산
- 합병/영업양도 등 근속기간 승계 판단 로직

## 범위 밖
- **세금 계산**: 퇴직소득세, 4대보험 정산 등은 이 계산기가 다루지 않는다. 별도 계산기 영역의 몫이다. FAQ에 "퇴직금 세금은 얼마인가요?" 질문은 남기되, 답변은 세액 계산 없이 범위 안내로 대체한다(위 Must Have "소개 콘텐츠 + FAQ 섹션" 참고).
- **퇴직연금(DC/DB) 관련 계산**: 법정 퇴직금(일시금) 산정만 다루며, 퇴직연금 제도 비교·수익률 계산은 다루지 않는다.
- **중간정산**: 재직 중 중간정산 퇴직금 계산은 다루지 않는다. 입사일부터 퇴사일까지 단일 기간 기준 계산만 다룬다.
- **근속기간 승계 판단**: 합병·영업양도·전적 등으로 인한 계속근로기간 승계 여부는 사용자가 직접 판단해 입사일에 반영해야 하며, 이 계산기는 입력된 입사일~퇴사일을 그대로 사용한다.
- **계산 공식의 세부 확정**: 평균임금 산정 방식의 정밀도(전 단위 처리), 반올림 규칙, 상여금·연차수당 가산 방식의 정확한 법적 근거 등 공식 자체의 정의·검증은 Product Owner가 아닌 Formula Analyst 단계의 책임이다.
- **관련 도구(다른 계산기) 링크 (v2 신규)**: 이번 라운드에서는 타 계산기로의 "관련 도구" 링크를 추가하지 않는다. 현재 사이트에 다른 계산기가 아직 없어(또는 충분히 없어) 연결 시 깨진 링크(dead link)가 되므로, 다른 계산기가 실제로 published 되기 전까지는 범위 밖으로 둔다.
