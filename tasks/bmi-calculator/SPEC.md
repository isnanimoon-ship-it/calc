# SPEC: BMI 계산기

## 목적

생년월일·성별·키·체중을 입력하면 BMI를 계산하고, 대한민국 기준에 맞춰 연령대별로 해석한다.
성인은 동일한 BMI 등급을 사용하고, 소아·청소년은 질병관리청 성장도표의 성별·월령별
백분위수를 사용한다. 선택적으로 허리둘레를 입력하면 성인의 성별별 복부비만 기준도 함께 보여준다.

BMI는 선별 지표이며 체지방률이나 질환을 진단하지 않는다. 임신, 부종, 근육량이 매우 많은 경우,
성장기 아동은 의료진의 종합 평가가 우선한다.

## 핵심 사용자 흐름

1. 생년월일과 성별을 선택한다.
2. 키(cm)와 체중(kg)을 입력한다.
3. 기준일은 대한민국 시간 기준 오늘을 기본값으로 사용한다.
4. 성인은 필요하면 허리둘레를 추가한다.
5. BMI와 연령대에 맞는 판정, 정상 범위 참고 체중을 확인한다.
6. 소아·청소년은 성별·완성 월령 기준 백분위수와 성장도표 위치를 확인한다.

## Must Have

### 입력

- 생년월일: 필수, 날짜 입력
- 기준일: 필수, Asia/Seoul 기준 오늘이 기본값
- 성장도표상 성별: 필수, `남아/남성` 또는 `여아/여성`
- 키: 필수, cm, 소수 첫째 자리 허용, 40.0~250.0cm
- 체중: 필수, kg, 소수 첫째 자리 허용, 2.0~500.0kg
- 허리둘레: 만 19세 이상에서만 선택 입력, cm, 소수 첫째 자리 허용, 40.0~200.0cm
- 생년월일은 기준일보다 늦을 수 없다.
- 입력이 바뀌면 기존 결과를 숨긴다.

성별 입력은 성 정체성을 판정하기 위한 항목이 아니라 성장도표와 허리둘레 기준 선택에 필요한
분류임을 도움말로 설명한다. 성인은 허리둘레를 입력하지 않으면 성별에 따른 계산 차이가 없다.

### 연령 분기

- 만 2세 미만(완성 월령 0~23개월): BMI 수치는 계산하되 BMI 등급·백분위 판정을 제공하지 않는다.
  이 연령은 신장별 체중 등 별도 성장지표로 평가해야 한다고 안내한다.
- 만 2세 이상 만 19세 미만(완성 월령 24~227개월): 2017 소아청소년 성장도표의 성별·완성
  월령별 BMI LMS 값으로 백분위수를 계산한다.
- 만 19세 이상(완성 월령 228개월 이상): 대한민국 성인 BMI 등급을 적용한다.
- 월령은 기준일에 완전히 지난 달만 세며 일수는 버린다. 예: 72개월 15일은 72개월.

### 핵심 결과

- BMI를 소수 첫째 자리까지 가장 크게 표시한다.
- 적용 기준을 `성인 기준`, `남아 84개월 성장도표 기준`처럼 함께 표시한다.
- 판정명과 경계 구간을 텍스트로 표시한다.
- 입력 키·체중, 만 나이/완성 월령, 적용 성별을 결과 상세에 표시한다.
- 계산식에 실제 입력값을 대입해 보여준다.

### 성인 결과

- 저체중: BMI < 18.5
- 정상: 18.5 ≤ BMI < 23.0
- 비만 전단계: 23.0 ≤ BMI < 25.0
- 1단계 비만: 25.0 ≤ BMI < 30.0
- 2단계 비만: 30.0 ≤ BMI < 35.0
- 3단계 비만: BMI ≥ 35.0
- 정상 BMI 18.5~22.9에 해당하는 참고 체중 범위를 표시한다.
- 허리둘레 입력 시 남성 90cm 이상, 여성 85cm 이상을 복부비만 기준으로 판정한다.
- 허리둘레 결과는 BMI 등급과 별개의 보조 지표로 표시한다.

### 소아·청소년 결과

- BMI 백분위수와 Z-score를 표시한다.
- 저체중: 5백분위수 미만
- 정상: 5백분위수 이상 85백분위수 미만
- 과체중: 85백분위수 이상 95백분위수 미만
- 비만: 95백분위수 이상
- 5·85·95백분위수에 해당하는 해당 성별·월령 BMI 경계를 함께 표시한다.
- 정상 체중 범위는 현재 키에서 5백분위 BMI 이상 85백분위 BMI 미만에 대응하는 참고값으로
  표시하되, 목표 체중이나 감량 권고로 표현하지 않는다.
- 백분위수는 소수 첫째 자리까지 표시하되 0.1 미만과 99.9 초과는 각각 `<0.1`, `>99.9`로 표시한다.

### 결과 안내

- BMI는 체중(kg)을 키(m)의 제곱으로 나눈 선별 지표라고 설명한다.
- 같은 BMI라도 체지방량·근육량·질환 위험이 다를 수 있음을 안내한다.
- 소아·청소년은 한 번의 측정보다 성장곡선의 변화가 중요하다고 안내한다.
- 만 19세 경계에서 판정 기준이 성장도표에서 성인 기준으로 전환됨을 명시한다.
- 임신 중에는 이 계산 결과로 체중 상태를 판정하지 않도록 안내한다.

### 공유·공통 UI

- 공통 `ShareActions`를 계산 전·후 동일 위치에 사용한다.
- 결과 공유 상태에는 생년월일, 기준일, 성별, 키, 체중, 허리둘레만 Base64URL로 저장한다.
- 공유 URL 복원 시 동일한 검증을 통과한 경우에만 자동 계산한다.
- 소개 → 입력 → 공유 → 핵심 결과 → 상세 → 계산 방법 → 기준/주의사항 → FAQ 순서를 따른다.
- 모바일 320px부터 가로 스크롤 없이 동작하고 결과 갱신 영역에 `aria-live="polite"`를 적용한다.

## Should Have

- BMI 구간을 표시하는 가로 스케일과 현재 위치 마커
- 키를 유지한 상태에서 각 판정 경계 체중 표시
- 이전 측정값과 비교할 수 있는 단일 추가 행
- 측정 방법 안내(맨발 키, 가벼운 복장 체중, 허리둘레 위치)
- 성장도표의 5·50·85·95백분위 위치를 간단한 그래프로 표시

## Could Have

- 인쇄/PDF 결과

## 성공 지표와 완료 기준

- 성인 등급 경계값 18.5·23·25·30·35 테스트 불일치 0건
- 남녀 허리둘레 경계 85·90cm 테스트 불일치 0건
- 24개월·228개월 연령 전환 경계 오류 0건
- 공식 성장도표 표본 20개 이상에서 BMI 백분위/Z-score 허용오차 이내
- 전체 계산·검증 Golden Test 30개 이상
- Critical·High 정확성 및 의료 오해 문구 결함 0건
