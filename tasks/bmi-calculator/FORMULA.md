# FORMULA: BMI 계산기

## 입력값

| 변수명 | 설명 | 내부 단위 | 허용 범위 |
|---|---|---:|---:|
| `birthDate` | 생년월일 | ISO 날짜 | 기준일 이하 |
| `referenceDate` | 계산 기준일 | ISO 날짜 | 지원 범위 내 |
| `sex` | 성장도표/허리둘레 기준 성별 | `male \| female` | 필수 |
| `heightCm` | 키 | cm | 40.0~250.0 |
| `weightKg` | 체중 | kg | 2.0~500.0 |
| `waistCm` | 허리둘레, 성인 선택 | cm | 40.0~200.0 |

## 출력값

| 변수명 | 설명 | 단위 |
|---|---|---|
| `bmiExact` | 반올림 전 BMI | kg/m² |
| `bmiDisplay` | 소수 첫째 자리 표시 BMI | kg/m² |
| `completedMonths` | 기준일 현재 완성 월령 | 개월 |
| `ageStandard` | 판정 기준 | infant / pediatric / adult |
| `category` | 연령 기준 판정 | 문자열 enum |
| `zScore` | 소아청소년 LMS Z-score | SD |
| `percentile` | 소아청소년 BMI 백분위수 | % |
| `thresholds` | 적용된 BMI 경계 | kg/m² |
| `referenceWeightRange` | 현재 키에 대응하는 참고 체중 범위 | kg |
| `abdominalObesity` | 성인 허리둘레 판정 | boolean / null |

## 공식

### BMI

```text
heightM = heightCm / 100
BMI = weightKg / heightM²
```

분류에는 반올림 전 `BMI`를 사용하고 표시할 때만 소수 첫째 자리로 반올림한다. 예를 들어 실제
BMI 22.96은 표시상 23.0이어도 정상 구간이며, 판정 옆에 실제 경계 기준을 함께 표시한다.

### 완성 월령

```text
months = (기준연도 - 출생연도) × 12 + (기준월 - 출생월)
기준일의 일(day)이 출생일보다 작으면 months에서 1을 뺀다.
```

월말 출생자는 달력상 완전히 지난 개월만 센다. 날짜 계산은 로컬 시간대 `Date` 차이가 아니라
연·월·일 정수 연산으로 수행한다.

### 성인 분류

`BMI`의 반올림 전 값으로 다음 반개방 구간을 적용한다.

| 분류 | 범위 |
|---|---|
| 저체중 | `< 18.5` |
| 정상 | `18.5 ≤ x < 23.0` |
| 비만 전단계 | `23.0 ≤ x < 25.0` |
| 1단계 비만 | `25.0 ≤ x < 30.0` |
| 2단계 비만 | `30.0 ≤ x < 35.0` |
| 3단계 비만 | `35.0 ≤ x` |

```text
정상 참고 체중 하한 = 18.5 × heightM²
정상 참고 체중 상한 경계 = 23.0 × heightM²
```

표시는 하한을 0.1kg 단위 올림, 상한은 23.0 미만을 보장하도록 0.1kg 단위 내림한다.

### 성인 허리둘레

```text
male: waistCm >= 90
female: waistCm >= 85
```

### 소아·청소년 LMS

완성 월령과 성별에 해당하는 공식 데이터의 `L`, `M`, `S`를 조회한다.

```text
L != 0: z = ((BMI / M)^L - 1) / (L × S)
L == 0: z = ln(BMI / M) / S
percentile = Φ(z) × 100
```

`Φ`는 표준정규분포 누적분포함수다. 5·85·95백분위 경계는 공식 데이터가 제공하는 값을
우선 사용하고, LMS로 역산할 때는 아래 공식을 쓴다.

```text
L != 0: BMI(p) = M × (1 + L × S × z(p))^(1/L)
L == 0: BMI(p) = M × exp(S × z(p))
```

분류는 반올림하지 않은 백분위 또는 공식 경계 BMI로 수행한다.

## 계산 순서

1. 날짜·성별·키·체중·허리둘레를 검증한다.
2. BMI와 완성 월령을 계산한다.
3. 24개월 미만, 24~227개월, 228개월 이상으로 기준을 선택한다.
4. 소아·청소년이면 성별·월령 LMS를 조회해 Z-score와 백분위를 계산한다.
5. 성인이면 고정 BMI 등급과 선택 허리둘레 기준을 적용한다.
6. 해당 경계 BMI를 현재 키의 참고 체중으로 환산한다.
7. 모든 표시값을 마지막에 한 번만 반올림한다.

## 정밀도 / 반올림 정책

- 내부 BMI·LMS·백분위 계산: JavaScript `number` 완전정밀도 유지
- BMI, 키, 체중, 경계값 표시: 소수 첫째 자리
- Z-score: 소수 둘째 자리
- 백분위수: 소수 첫째 자리, `<0.1`/`>99.9` clamp 표기
- 판정은 표시값이 아닌 반올림 전 값을 사용
- 사용자가 입력한 키·체중은 임의 반올림하지 않고 검증 후 계산에 사용

## 예외

- 키나 체중이 0·음수·NaN이면 계산하지 않는다.
- 생년월일이 기준일보다 늦으면 계산하지 않는다.
- 만 2세 미만은 BMI 숫자만 제공하고 체중상태 판정을 반환하지 않는다.
- 성장도표 데이터에 해당 성별·월령 행이 없으면 성인 기준으로 대체하지 않고 판정 불가를 표시한다.
- 정확히 24개월이면 소아 성장도표, 정확히 228개월이면 성인 기준을 적용한다.
- 허리둘레는 성인에게만 해석하며 소아 입력에는 사용하지 않는다.
- 임신 여부는 입력받지 않으므로 결과 안내에서 적용 한계를 명확히 표시한다.

## Golden Test 후보

1. 170cm·70kg → BMI 약 24.221, 표시 24.2, 성인 비만 전단계
2. 160cm·64kg → BMI 25.0, 성인 1단계 비만
3. 각 성인 경계 직전·정확히 경계: 18.5, 23, 25, 30, 35
4. 남성 허리 89.9/90.0cm, 여성 84.9/85.0cm
5. 23개월 마지막 날 → 판정 없음, 24개월 당일 → 성장도표
6. 227개월 마지막 날 → 성장도표, 228개월 당일 → 성인 기준
7. 질병관리청 남아·여아 각 24·60·120·180·227개월의 5·50·85·95백분위 표본
8. 월말·윤일 출생자의 완성 월령 경계

구현 전 공식 성장도표 원자료에서 기대값을 추출해 20개 이상의 고정 Golden Test로 확정한다.
