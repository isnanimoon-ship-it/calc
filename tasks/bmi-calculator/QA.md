# QA: BMI 계산기

## 기능 테스트

- BMI 공식과 실제 값 대입식 일치
- 성인 6개 구간과 각 경계 직전/정확히 경계 판정
- 소아 남녀·월령별 LMS 조회, Z-score, 백분위, 4개 구간 판정
- 24개월·228개월 기준 전환
- 남녀 허리둘레 기준과 미입력 상태
- 정상 참고 체중 범위의 반올림 및 경계 포함 관계
- 계산 전/후 공유와 Base64URL 자동 복원
- 입력 수정 시 이전 결과 제거

## 데이터 품질

- 공식 2017 성장도표와 남녀 각 10개 이상 표본 대조
- 월령 행 누락·중복 없음
- 공식 원본 checksum과 변환 산출물 기록 확인
- 2027 데이터가 공식 공개 전 혼입되지 않았는지 확인

## 입력 검증

- 빈 날짜·성별·키·체중
- 존재하지 않는 날짜와 날짜 역전
- 키 39.9/40/250/250.1cm
- 체중 1.9/2/500/500.1kg
- 허리둘레 39.9/40/200/200.1cm
- 음수, 0, NaN, Infinity, 문자, 소수 둘째 자리

## 의료 표현 점검

- BMI를 진단 또는 체지방률로 표현하지 않음
- 성인 BMI 기준을 남녀별로 다르게 적용하지 않음
- 소아 결과를 목표 체중·감량 권고로 표현하지 않음
- 만 2세 미만에 BMI 등급을 표시하지 않음
- 임신·부종·고근육량·성장곡선 관련 한계 고지
- 위급성 판단이나 치료 권고를 제공하지 않음

## 접근성·반응형

- label, 도움말, 오류 연결 및 `aria-live`
- 분류를 색상만으로 전달하지 않음
- BMI 스케일을 텍스트 표로도 동일하게 제공
- 320 / 375 / 390 / 768 / 1440px 가로 스크롤 없음
- 라이트·다크 모드 WCAG AA 확인
- 키보드만으로 성별 선택·계산·공유 가능

## 브라우저

- Chromium, Firefox, Safari 최신 주요 버전
- 모바일 날짜·decimal 키패드
- 시간대 변경에도 완성 월령이 바뀌지 않음
- 새로고침 및 공유 URL 직접 진입
