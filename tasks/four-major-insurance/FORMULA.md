# FORMULA: 4대 보험 계산기

## 상태

- 기준 연도: 2026년
- 적용 기준일: 2026-09-04
- v1 요율 적용기간: **2026-07-01 이후 현재 월 보험료 추정**
- 마지막 검토: 2026-09-04
- 다음 재검토 예정일: 2027-01-01

2026년 국민연금 보험료율은 9.5%로 연중 동일하지만 기준소득월액 상·하한은 7월 1일에
변경된다. v1은 과거 급여명세서를 재현하는 계산기가 아니라 현재 보험료를 추정하는 도구이므로
2026년 7월 1일부터 2027년 6월 30일까지 적용되는 하한 410,000원·상한 6,590,000원을
사용한다. 화면에는 단순히 `2026년 기준`이라고만 쓰지 말고 **`2026년 7월 이후 기준`**이라고
표시한다.

---

## 목적

일반 직장가입자의 월 보수 추정값을 바탕으로 국민연금, 건강보험, 장기요양보험, 고용보험의
근로자 부담액과 사업주 부담액을 계산한다. 근로자가 실제 급여에서 부담하는 합계와 4대 보험
공제 후 금액을 핵심 결과로 제공한다.

산재보험은 근로자 부담이 없고 28개 사업종류별 요율이 다르므로 v1 금액 계산에서 제외한다.
사업주 합계에는 `산재보험 제외`를 명시한다. 2026년 전 업종 평균 산재보험료율 1.47%는 안내
목적으로만 사용할 수 있으며 개별 사업장의 계산 요율로 사용하면 안 된다.

---

## v1 전제와 범위

- 대한민국 사업장의 일반 근로자·직장가입자 1명을 대상으로 한다.
- 사용자가 입력한 `월 급여 - 비과세 금액`을 신고된 기준소득월액·보수월액의 근사값으로 본다.
- 신규 취득자의 신고소득, 전년도 보수총액 정산, 소급분, 휴직, 일할 계산은 반영하지 않는다.
- 국민연금·건강보험·고용보험은 사용자가 가입 여부를 각각 선택할 수 있다.
- 장기요양보험은 건강보험과 연동되며 독립적으로 선택할 수 없다.
- 두루누리 등 보험료 지원금은 반영하지 않는다.
- 소득세·지방소득세를 계산하지 않으므로 `실수령액`이라는 명칭을 사용하지 않는다.
- 고용보험 사업주 부담은 기본적으로 `150인 미만 기업` 요율을 사용하며 사용자가 다른 구간을
  선택할 수 있게 한다.

---

## 입력값

| 변수명 | 설명 | 단위 | 허용 범위 / 기본값 |
|---|---|---|---|
| `monthlyGrossPay` | 세전 월 급여. 비과세 항목을 포함해 사용자가 실제 받는 월 급여 총액 | 원 | 필수 정수, `> 0`, `<= 1,000,000,000` |
| `monthlyNonTaxablePay` | 월 급여 중 실비변상적 급여 등 사회보험 산정에서 제외할 비과세 금액의 간편 입력값 | 원 | 선택 정수, 기본 `0`, `0 <= 값 <= monthlyGrossPay` |
| `nationalPensionEnabled` | 국민연금 계산 여부 | boolean | 기본 `true` |
| `healthInsuranceEnabled` | 건강보험 및 장기요양보험 계산 여부 | boolean | 기본 `true` |
| `employmentInsuranceEnabled` | 고용보험 계산 여부 | boolean | 기본 `true` |
| `employmentBusinessRateTier` | 사업주 고용안정·직업능력개발사업 요율 구간 | enum | 기본 `under150` |

`employmentBusinessRateTier` 값:

| 값 | 사용자 표시 | 사업주 추가 요율 |
|---|---|---:|
| `under150` | 150인 미만 기업 | 0.25% |
| `priorityOver150` | 150인 이상 우선지원대상기업 | 0.45% |
| `between150And999` | 150인 이상 1,000인 미만 기업 | 0.65% |
| `over1000OrGovernment` | 1,000인 이상 기업·국가·지자체 | 0.85% |

### 입력값에 대한 중요한 한계

비과세소득과 사회보험 산정 제외 보수는 완전히 같은 개념이 아니다. 이 계산기는 일반 사용자의
입력 편의를 위해 `월 급여 - 비과세 금액`을 공통 추정 보수로 사용한다. 실제 공단 신고액과
다를 수 있으므로 결과 화면에서 이를 고지한다.

### 국민연금 — 2026년 7월 이후

| 상수 | 값 | 근거 |
|---|---:|---|
| 총 보험료율 | 9.5% | 국민연금공단 2026년 보험료율 안내 |
| 근로자 기여금률 | 4.75% | 총 보험료의 1/2 |
| 사용자 부담금률 | 4.75% | 총 보험료의 1/2 |
| 기준소득월액 하한 | 410,000원 | 2026-07-01~2027-06-30 적용 |
| 기준소득월액 상한 | 6,590,000원 | 2026-07-01~2027-06-30 적용 |
| 기준소득월액 단위 | 1,000원 | 실제 소득월액에서 천 원 미만 절사 |

참고로 2025-07-01~2026-06-30 적용 상·하한은 400,000원·6,370,000원이지만 v1 계산에는
사용하지 않는다.

### 건강보험·장기요양보험 — 2026년

| 상수 | 값 | 근거 |
|---|---:|---|
| 직장가입자 건강보험 총 보험료율 | 7.19% | 국민건강보험공단 2026년도 보험료율 안내 |
| 근로자 건강보험 부담률 | 3.595% | 총 보험료의 50% |
| 사용자 건강보험 부담률 | 3.595% | 총 보험료의 50% |
| 장기요양보험료율 | 0.9448% | 국민건강보험공단 2026년도 보험료율 안내 |
| 건강보험료 대비 장기요양 비율 | `0.9448 / 7.19` ≈ 13.140472879% | 공단 공식 산식 |
| 직장 보수월액 건강보험료 총액 하한 | 20,160원 | 보건복지부고시 제2025-222호 |
| 직장 보수월액 건강보험료 총액 상한 | 9,183,480원 | 보건복지부고시 제2025-222호 |

상·하한은 근로자 개인 부담액이 아니라 사용자 부담을 합친 **보수월액보험료 총액** 기준이다.
따라서 총 보험료에 상·하한을 적용한 뒤 근로자와 사용자가 각각 50%를 부담한다.

### 고용보험 — 일반 근로자

| 상수 | 값 | 부담 주체 |
|---|---:|---|
| 실업급여 보험료율 | 1.8% | 근로자 0.9% + 사업주 0.9% |
| 고용안정·직업능력개발사업 | 0.25%~0.85% | 사업주 전액 |

근로자 고용보험 부담률은 사업장 규모와 무관하게 0.9%다. 사업주의 총 고용보험 부담률만
`0.9% + 선택 구간 추가 요율`로 달라진다.

### 산재보험

- 근로자 부담률: 0%
- 사업주가 전액 부담
- 2026년 평균 산재보험료율: 1.47%(안내용)
- 실제 요율: 28개 사업종류별 보험료율 + 출퇴근재해 요율 등으로 결정
- **v1 계산값: 제공하지 않음**. 평균 1.47%를 사용자의 사업장 요율로 대체하지 않는다.

## 공통 보조 함수

부동소수점 오차를 피하기 위해 요율은 정수 분수로 저장한다. 예를 들어 4.75%는
`475 / 10,000`, 3.595%는 `3,595 / 100,000`으로 표현한다.

```text
truncateTo10Won(value) = floor(value / 10) * 10
clamp(value, min, max) = min(max(value, min), max)
```

모든 입력은 원 단위 정수다. `Number` 안전 정수 범위를 충분히 벗어나지 않도록 입력 상한을
10억 원으로 제한한다.

---

## 공식

### 1. 공통 추정 보수

```text
estimatedMonthlyRemuneration = monthlyGrossPay - monthlyNonTaxablePay
```

`estimatedMonthlyRemuneration`이 0이면 모든 보험 계산을 진행하지 않고 산정 대상 보수가 없다는
안내를 반환한다.

### 2. 국민연금

```text
rawPensionIncome = floor(estimatedMonthlyRemuneration / 1,000) * 1,000

pensionStandardMonthlyIncome = clamp(
  rawPensionIncome,
  410,000,
  6,590,000
)

employeePension = truncateTo10Won(
  pensionStandardMonthlyIncome * 475 / 10,000
)

employerPension = truncateTo10Won(
  pensionStandardMonthlyIncome * 475 / 10,000
)
```

`nationalPensionEnabled = false`이면 두 부담액은 0원이며 결과에 `미가입으로 설정`을 표시한다.
국민연금법 제117조 및 국민연금공단 사업장 실무안내에 따라 보험료의 10원 미만은 절사한다.

### 3. 건강보험

먼저 사용자 부담을 포함한 총 보험료에 법정 상·하한을 적용하고, 그 뒤 절반을 각 부담액으로
나눈다.

```text
rawHealthTotal = estimatedMonthlyRemuneration * 719 / 10,000

healthTotal = clamp(
  truncateTo10Won(rawHealthTotal),
  20,160,
  9,183,480
)

employeeHealth = truncateTo10Won(healthTotal / 2)
employerHealth = healthTotal - employeeHealth
```

통상 `healthTotal`은 10원 단위이므로 양쪽이 같다. 홀수 단위 등 분할 차이가 발생하는 경우 총액
보존을 위해 사업주 부담액을 `healthTotal - employeeHealth`로 둔다.

### 4. 장기요양보험

공단 공식 산식은 `건강보험료 × 장기요양보험료율 ÷ 건강보험료율`이다. 각 부담 주체의 확정된
건강보험료를 기준으로 계산한다.

```text
employeeLongTermCare = truncateTo10Won(
  employeeHealth * 9,448 / 71,900
)

employerLongTermCare = truncateTo10Won(
  employerHealth * 9,448 / 71,900
)
```

`healthInsuranceEnabled = false`이면 건강보험과 장기요양보험을 모두 0원으로 처리한다.

### 5. 고용보험

```text
employeeEmployment = truncateTo10Won(
  estimatedMonthlyRemuneration * 9 / 1,000
)

employerUnemployment = truncateTo10Won(
  estimatedMonthlyRemuneration * 9 / 1,000
)

employerEmploymentStability = truncateTo10Won(
  estimatedMonthlyRemuneration * selectedEmployerExtraRate
)

employerEmployment = employerUnemployment + employerEmploymentStability
```

`selectedEmployerExtraRate`는 각각 `25/10,000`, `45/10,000`, `65/10,000`, `85/10,000`이다.
`employmentInsuranceEnabled = false`이면 관련 부담액을 모두 0원으로 처리한다.

### 6. 합계

```text
employeeInsuranceTotal =
  employeePension
  + employeeHealth
  + employeeLongTermCare
  + employeeEmployment

employerInsuranceTotalExcludingWorkersComp =
  employerPension
  + employerHealth
  + employerLongTermCare
  + employerEmployment

combinedInsuranceTotalExcludingWorkersComp =
  employeeInsuranceTotal
  + employerInsuranceTotalExcludingWorkersComp

afterEmployeeInsurance = monthlyGrossPay - employeeInsuranceTotal
```

`afterEmployeeInsurance`에는 소득세·지방소득세가 빠지지 않았으므로 화면 라벨을 반드시
`4대 보험 공제 후 금액`으로 사용한다.

## 계산 순서

1. 월 급여와 비과세 금액의 형식·범위를 검증한다.
2. `estimatedMonthlyRemuneration`을 계산한다.
3. 가입 선택 상태를 확인한다. 모두 해제됐으면 계산 대신 선택 확인 안내를 표시한다.
4. 국민연금 기준소득월액을 천 원 단위로 만든 뒤 상·하한을 적용한다.
5. 국민연금 근로자·사업주 부담액을 계산하고 10원 미만 절사한다.
6. 건강보험 총액을 계산하고 총액 상·하한을 적용한 뒤 근로자·사업주가 나눈다.
7. 확정 건강보험 부담액을 기준으로 장기요양보험료를 계산한다.
8. 고용보험 근로자 부담액과 사업주 부담액을 각각 계산한다.
9. 근로자 합계·사업주 합계·전체 합계를 계산한다.
10. 월 급여에서 근로자 부담 합계만 차감해 4대 보험 공제 후 금액을 계산한다.
11. 보험별 적용 기준, 상·하한 적용 여부, 산재보험 제외 및 실제 고지액 차이 가능성을 표시한다.

---

## 단위와 정밀도

- 입력·출력 금액: 원 단위 정수
- 요율: UI에는 `%`, 내부에서는 정수 분수의 분자·분모
- 내부 자료형: JavaScript `number`
- 국민연금 기준소득월액: 천 원 미만 절사 후 상·하한 적용
- 보험료: 각 보험·부담 주체별 최종 단계에서 10원 미만 절사
- 반올림된 값을 다른 보험의 기준으로 재사용하지 않는다. 단, 장기요양보험은 법정 산식 자체가
  건강보험료를 기준으로 하므로 확정 건강보험료를 사용한다.
- 합계에는 화면 표시값과 동일한 확정 보험료를 사용한다.

### 구현 시 주의

`3,000,000 * 0.009`처럼 부동소수점 소수를 직접 곱한 뒤 `floor`하면 런타임 표현 오차로
26,999.999...가 되어 26,990원으로 잘못 절사될 수 있다. 반드시 정수 분수
`3,000,000 * 9 / 1,000` 형태로 계산한다.

---

## 예외와 검증

- `monthlyGrossPay` 빈 값, 0, 음수, 소수, 숫자 아님 → 계산하지 않음.
- `monthlyNonTaxablePay` 음수·소수·숫자 아님 → 계산하지 않음.
- `monthlyNonTaxablePay > monthlyGrossPay` → 계산하지 않음.
- `estimatedMonthlyRemuneration = 0` → 보험료 0원을 결과처럼 보여주지 않고 산정 대상 보수가
  없다는 안내를 표시.
- 모든 보험을 해제 → 계산하지 않고 하나 이상의 보험을 선택하도록 안내.
- 건강보험 해제 → 장기요양보험도 자동 해제.
- 국민연금 산정 보수 410,000원 미만 → 410,000원 하한 적용 사실 표시.
- 국민연금 산정 보수 6,590,000원 초과 → 6,590,000원 상한 적용 사실 표시.
- 건강보험 총 보험료가 20,160원 미만 또는 9,183,480원 초과 → 총액 상·하한 적용 사실 표시.
- 월 중 자격 취득·상실, 휴직, 두 개 이상 사업장, 보험료 지원 → v1 미반영 고지.
- 국민연금 가입연령이나 고용보험 적용 제외 등 실제 가입 자격 → 사용자의 선택을 따르며 법적
  판정을 하지 않음.
- 산재보험 → 근로자 부담 0원, 사업주 금액은 `업종별 요율 필요`로 표시.

## 검증 예제 (Golden Test 후보)

아래 값은 모두 2026년 7월 이후 요율, 비과세 0원, 세 보험 가입, 사업장 구간
`150인 미만(사업주 추가 0.25%)`을 기본으로 한다. 산재보험은 합계에서 제외한다.

### 예제 1 — 월 급여 3,000,000원

- 국민연금 기준소득월액: 3,000,000원
- 근로자: 국민연금 142,500원, 건강보험 107,850원, 장기요양 14,170원, 고용보험 27,000원
- 근로자 합계: **291,520원**
- 4대 보험 공제 후 금액: **2,708,480원**
- 사업주 합계(산재 제외): **299,020원**
- 산술 검증: 정수 분수 공식으로 자체 계산, 2026-09-04

### 예제 2 — 월 급여 2,000,000원

- 근로자: 국민연금 95,000원, 건강보험 71,900원, 장기요양 9,440원, 고용보험 18,000원
- 근로자 합계: **194,340원**
- 4대 보험 공제 후 금액: **1,805,660원**
- 사업주 합계(산재 제외): **199,340원**
- 국민연금공단 공식 예시가 기준소득월액 2,000,000원의 총 보험료 190,000원,
  근로자·사용자 각 95,000원을 제시하므로 국민연금 값과 직접 일치
- 출처 확인일: 2026-09-04

### 예제 3 — 비과세 금액 적용

- Input: 월 급여 3,200,000원, 비과세 200,000원
- 산정 보수: 3,000,000원
- 보험별 부담액은 예제 1과 동일
- 근로자 합계: 291,520원
- 4대 보험 공제 후 금액: **2,908,480원** (`3,200,000 - 291,520`)

### 예제 4 — 국민연금 하한 바로 아래

- Input: 월 급여 400,000원
- 국민연금 기준소득월액: **410,000원(하한 적용)**
- 국민연금 근로자 부담: `410,000 × 4.75% = 19,475 → 19,470원`
- 하한 적용 플래그: true

### 예제 5 — 국민연금 하한 경계

- Input: 월 급여 410,000원
- 국민연금 기준소득월액: 410,000원

### 예제 9 — 일부 보험 미가입 설정

### 예제 11 — 사업장 규모별 사업주 고용보험

- Input: 월 급여 3,000,000원
- 사업주 실업급여 부담: 27,000원
