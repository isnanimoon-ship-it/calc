# SPEC: 만 나이 계산기

## 목적

생년월일과 기준일을 입력하면 법적·행정적 기본 기준인 만 나이와 정확한 경과 연·월·일,
다음 생일까지 남은 날을 계산한다. 과거에 널리 쓰이던 세는나이와 일부 법령에서 사용하는
연 나이는 참고값으로 명확히 구분해 보여준다.

민법 제158조와 행정기본법 제7조의2에 따라 별도 규정이 없는 나이는 출생일을 산입해 만 나이로
계산하고 연수로 표시한다. 특정 제도는 별도의 연령 산정일이나 연 나이를 사용할 수 있으므로,
계산 결과만으로 개별 제도의 자격을 확정하지 않는다.

## 주요 사용자

- 현재 또는 특정 날짜 기준 만 나이를 확인하려는 사용자
- 생일 전후로 나이가 언제 바뀌는지 확인하려는 사용자
- 계약·신청·행정업무 전 참고 나이를 확인하려는 사용자
- 만 나이, 세는나이와 연 나이의 차이를 이해하려는 사용자

## 핵심 사용자 흐름

1. 생년월일을 입력한다.
2. 기준일을 입력한다. 기본값은 대한민국 시간 기준 오늘이다.
3. 계산 버튼을 누른다.
4. 만 나이와 정확한 나이 `N년 N개월 N일`을 확인한다.
5. 다음 생일 날짜와 D-day, 태어난 지 지난 일수를 확인한다.
6. 필요하면 세는나이·연 나이의 참고값과 계산 차이를 확인한다.
7. 계산 방법과 법적 기준, 윤년·2월 29일 처리 원칙을 확인한다.

## Must Have

### 입력

- **생년월일**: 필수 날짜 입력
- **기준일**: 필수 날짜 입력, Asia/Seoul 기준 오늘을 기본값으로 설정
- 기준일은 과거·오늘·미래 모두 입력 가능하되 생년월일보다 빠를 수 없다.
- 지원 범위는 1900-01-01부터 2200-12-31까지로 제한한다.
- 입력값은 브라우저에서만 계산하며 서버로 전송하거나 저장하지 않는다.

### 핵심 결과

- **만 나이**를 가장 크게 `만 N세`로 표시한다.
- 만 1세 미만은 `만 0세`와 함께 `N개월 N일`을 강조해 표시한다.
- 정확한 경과기간을 `N년 N개월 N일`로 표시한다.
- 기준일이 생일이면 `오늘이 생일입니다` 상태를 표시한다.
- 생년월일과 기준일을 요약하고 각각 요일을 표시한다.

### 추가 정보

- **태어난 지 지난 일수**: 출생일을 0일차로 한 두 날짜 사이의 날짜 경계 수
- **다음 생일**: 생일 당일에는 D-0, 그 외에는 다음 생일 날짜와 `D-N`
- **이번 기준연도 생일 상태**: 생일 전·오늘·생일 지남
- **세는나이(과거 한국식 나이)**: `기준연도 - 출생연도 + 1`
- **연 나이**: `기준연도 - 출생연도`
- 세는나이와 연 나이는 법적 기본 나이가 아닌 참고값이라는 설명을 결과 바로 옆에 둔다.

### 띠·간지 정보

- 띠는 **음력 설날을 연도 경계로 하는 생활문화 기준**을 기본값으로 계산한다.
- 설날 이전 출생자는 직전 음력년의 띠, 설날 당일부터는 새 음력년의 띠를 적용한다.
- 십이지 동물뿐 아니라 해당 연도의 천간·오행·오방색을 결합한 이름을 표시한다.
  - 예: `황금 개띠` — 무술년(戊戌年), 토(土), 황색 계열
  - 예: `검은 뱀띠` — 계사년(癸巳年), 수(水), 검정 계열
- 핵심 결과에는 친숙한 표현을 사용하고, 상세 정보에는 간지와 오행을 함께 표시해 근거를
  확인할 수 있게 한다.
- `황금`은 황색·토 기운의 대중적 별칭임을 안내한다. 금(金) 오행을 뜻하는 표현으로 오해하게
  만들지 않는다.
- 사주·명리에서 사용하는 **입춘 기준**은 정확한 출생 시각과 연도별 절입 시각 데이터가
  필요하므로 v1 이후 고급 설정으로 제공한다.
- 한국천문연구원의 음양력·월력요항 데이터를 연도별 정적 스냅샷으로 검증해 사용한다.
- 띠·간지 지원 범위는 검증된 한국 음력 변환 데이터가 제공되는 1900-01-01~2050-12-31이다.
  이 범위 밖에서는 양력 출생연도만으로 띠를 추정하지 않는다.

### 계산 방법 안내

- 생일이 지났거나 당일이면 `기준연도 - 출생연도`, 지나지 않았으면 여기서 1을 빼는 만 나이
  공식을 실제 입력값과 함께 보여준다.
- 정확한 연·월·일은 기준일을 넘지 않는 완전한 달력 연, 월을 순서대로 차감한 뒤 남은 일수를
  계산한다고 설명한다.
- 출생일을 0일차로 보는 태어난 지 일수와 법률상 출생일 산입 원칙의 표현 차이를 설명한다.
- 2월 29일생은 평년의 대응일을 2월 말일로 보정하는 민법상 역법 계산 원칙을 안내한다.
- 별도 법령이 다른 기준을 정할 수 있다는 예외 고지를 표시한다.

### 오류와 경계

- 생년월일 또는 기준일 누락, 존재하지 않는 날짜를 거부한다.
- 생년월일이 기준일보다 늦으면 계산하지 않고 해당 입력 가까이에 오류를 표시한다.
- 지원 범위를 벗어난 날짜를 거부한다.
- 같은 날짜는 만 0세·0개월·0일·태어난 지 0일로 정상 계산한다.
- 생일 전날·당일·다음 날, 월말, 연말·연초와 윤년을 정확히 처리한다.
- 2월 29일생의 평년 생일 경계를 명시적으로 테스트한다.
- 브라우저·서버 시간대에 따라 날짜가 하루 이동하지 않아야 한다.

### 접근성·반응형

- 모든 날짜 입력에 연결된 label, 도움말과 오류 메시지를 제공한다.
- 결과 갱신 영역에 `aria-live="polite"`를 적용한다.
- 생일 상태와 결과 차이를 색상만으로 표현하지 않는다.
- D-day와 날짜를 보조기술이 읽을 수 있는 텍스트로 제공한다.
- 320px, 375px, 390px, 768px, 1440px에서 페이지 전체 가로 스크롤이 없어야 한다.
- 다크 모드는 기존 계산기의 저채도 결과 표면과 제한된 강조색을 사용한다.

### 공통 제품 요건

- `계산하기`, `오늘 기준 예시`, `초기화` 기능을 제공한다.
- 입력이 바뀌면 이전 결과를 숨겨 입력과 결과가 불일치하지 않게 한다.
- 결과 순서는 핵심 결과 → 입력·추가 정보 → 나이 종류 비교 → 계산 방법 → 법적 기준 → FAQ다.
- 소개, 사용 방법, FAQ와 `WebApplication`·`FAQPage` 구조화 데이터를 제공한다.
- 날짜 계산은 UI와 분리된 순수 함수로 구현한다.
- 공식 법제처 예시를 포함한 Golden Test 5개 이상, 전체 날짜·검증 테스트 20개 이상을 작성한다.
