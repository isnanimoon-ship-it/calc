# SPEC: 전역일 계산기

## 목적

복무 유형과 복무 시작일을 입력하면 대한민국 병역의무자의 예상 복무 종료일, 전체 복무기간,
남은 기간, 복무 진행률과 주요 일정을 한눈에 확인할 수 있게 한다. 현역병에게는 계급별 예상
진급 일정을 함께 제공하고, 보충역·대체복무 유형에는 해당 제도의 복무 종료 일정만 제공한다.

이 계산기는 현행 법령과 병무청이 안내하는 표준 의무복무기간을 달력에 적용하는 참고 도구다.
실제 전역·소집해제·복무만료일은 군 또는 복무기관의 인사명령, 복무 중단, 연장복무, 편입·전환,
징계 및 개인별 병적기록에 따라 달라질 수 있음을 명확히 안내한다.

## 주요 사용자

- 입영 또는 소집을 앞두고 예상 전역일을 확인하려는 사람
- 현재 복무 중 남은 날짜와 진행률을 확인하려는 장병·복무요원
- 가족·연인·지인이 주요 일정과 남은 기간을 확인하려는 경우
- 여러 복무 유형의 표준 복무기간을 비교하려는 사용자

## 핵심 사용자 흐름

1. 복무 종류를 선택한다.
2. 세부 복무 유형을 선택한다.
3. 입영일·소집일·편입일 등 복무 시작일을 입력한다.
4. 기준일은 기본값인 오늘을 사용하거나 다른 날짜로 변경한다.
5. 계산 버튼을 누른다.
6. 예상 전역일 또는 복무만료일, 남은 기간, 총 복무일수와 진행률을 확인한다.
7. 현역병이면 계급별 예상 진급 일정, 모든 유형에서는 주요 진행 이정표를 확인한다.
8. 상세 영역에서 적용된 복무기간과 날짜 계산 방식을 확인한다.

## Must Have

### 입력

- **복무 종류**: 현역병, 상근예비역, 보충역·대체복무 등 상위 그룹을 먼저 선택한다.
- **세부 복무 유형**: 상위 그룹에 따라 유효한 유형만 칩 또는 라디오 버튼으로 보여준다.
- **복무 시작일**: 필수 날짜 입력이다. 화면에는 선택 유형에 맞춰 `입영일`, `소집일`,
  `편입일`로 표현하되 내부 데이터 키는 하나로 통일한다.
- **계산 기준일**: 기본값은 사용자의 로컬 시간대(Asia/Seoul)의 오늘이다. 과거·미래 날짜로
  변경할 수 있어 입대 전 또는 특정 시점 기준 계산도 가능해야 한다.
- 선택한 복무 유형의 표준 복무기간을 입력 영역 가까이에 미리 표시한다.
- 입력값은 브라우저에서만 처리하며 서버로 전송하거나 저장하지 않는다.

### 핵심 결과

- 유형에 따라 결과 제목을 `예상 전역일`, `예상 소집해제일`, `예상 복무만료일`로 구분한다.
- 종료일을 `YYYY년 M월 D일` 형식으로 가장 크게 표시한다.
- 남은 기간을 달력 기준 `N년 N개월 N일`과 `D-N` 형식의 총 남은 일수로 함께 표시한다.
- 전체 복무기간을 개월 수와 총 달력 일수로 표시한다.
- 기준일까지 완료한 복무일수와 0~100% 복무 진행률을 표시한다.
- 시작 전이면 `입영까지 D-N`, 종료일이 지났으면 `복무 완료 후 D+N` 상태로 표시하고
  진행률은 각각 0%, 100%로 제한한다.
- 오늘을 기준일로 사용했을 때만 `오늘` 배지를 표시한다.

### 상세 내역

- 선택한 복무 유형, 복무 시작일, 적용한 표준 복무기간과 정책 기준일을 표시한다.
- 종료일 계산식을 실제 날짜가 대입된 형태로 보여준다.
  - 예: `2026.09.04 + 18개월 - 1일 = 2028.03.03`
- 남은 일수와 진행률 계산에 사용한 시작일·기준일·종료일을 표시한다.
- 결과의 일수 표기는 `시작일을 복무 1일차로 포함`하는지, D-day 차이는 날짜 경계 간 차이인지
  명시해 사용자가 하루 차이를 오해하지 않도록 한다.

### 일정 타임라인

- 공통 이정표: 복무 시작, 25%, 50%, 75%, 복무 종료.
- 각 이정표에 날짜, 기준일로부터의 D-day, 완료·오늘·예정 상태를 표시한다.
- 현역병·상근예비역에는 이병→일병→상병→병장의 **예상 진급 일정**을 추가한다.
- 진급 일정은 법령상 진급 최저복무기간을 기준으로 한 예상치이며 실제 진급은 진급심사,
  매월 1일 발령, 단축·연장 및 진급 제한으로 달라질 수 있다는 안내를 일정 바로 아래 표시한다.
- 보충역·대체복무 유형에는 군 계급 타임라인을 표시하지 않는다.

### 계산 방식

- 달력 월 덧셈은 실행 환경의 시간대나 DST에 영향을 받지 않는 순수 날짜 계산으로 구현한다.
- 표준 종료일의 기본 정의는 `복무 시작일 + 복무 개월 수 - 1일`로 한다. 다만 복무 유형별
  법령이 다른 기산 규칙을 요구하면 유형별 규칙을 정책 데이터에 명시한다.
- 월말 날짜에 월을 더할 때 JavaScript `Date#setMonth`의 넘침 동작을 그대로 사용하지 않는다.
  목표 월에 같은 날짜가 없으면 그 달의 마지막 날로 보정한 뒤 종료일 규칙을 적용한다.
- 화면의 `총 복무일수`는 첨부 예시와 동일하게 시작일에서 종료일까지의 날짜 경계 수로 정의한다.
  시작일과 종료일을 모두 세는 포함 일수는 이보다 1 크다는 점을 계산 방법에서 설명한다.
- 진행률은 `완료한 날짜 경계 수 ÷ 전체 날짜 경계 수 × 100`으로 계산하며 0~100%로 제한한다.
- 남은 `년·개월·일`은 종료일까지 순서대로 완전한 달력 연·월을 차감한 뒤 나머지 일수를
  계산한다. `일수 ÷ 365` 같은 단순 환산을 사용하지 않는다.
- 모든 기준 날짜를 `YYYY-MM-DD` 문자열로 받아 로컬 자정·UTC 변환 오차를 방지한다.

### 오류와 예외 처리

- 복무 유형 또는 복무 시작일이 없으면 계산하지 않고 해당 입력 가까이에 오류를 표시한다.
- 존재하지 않는 날짜와 지원 정책 범위를 벗어난 날짜를 거부한다.
- 기준일은 지원 가능한 날짜 범위 안에서만 허용한다.
- 복무 시작일이 미래인 경우 오류로 막지 않고 `입영 예정` 상태로 계산한다.
- 윤년(2월 29일), 월말(29·30·31일), 연도 경계와 같은 날짜 경계를 정확히 처리한다.
- 복무 중단·연장·편입 전환이 있는 사용자는 표준 계산 결과가 실제 병적기록과 다를 수 있음을
  결과 상단에서 확인할 수 있어야 한다.

### 접근성·반응형

- 복무 유형 선택은 실제 라디오 그룹으로 구현하고 키보드 방향키 또는 Tab/Space로 조작할 수
  있어야 한다. 색상만으로 선택 상태를 구분하지 않는다.
- 모든 날짜 입력은 연결된 label, 도움말, 오류 메시지를 갖는다.
- 결과 갱신 영역에 `aria-live="polite"`를 적용한다.
- 진행률은 텍스트 백분율과 접근 가능한 progress 의미를 함께 제공한다.
- 타임라인은 장식 그래픽과 별개로 날짜·상태를 읽을 수 있는 목록 구조를 제공한다.
- 320px, 375px, 390px, 768px, 1440px에서 페이지 전체 가로 스크롤이 없어야 한다.

### 공통 제품 요건

- `계산하기`, `오늘 입영 샘플`, `초기화` 기능을 제공한다.
- 결과는 핵심 카드 → 상세 내역 → 진행률·타임라인 → 계산 방법 → 정책 안내 → FAQ 순서로 둔다.
- 소개, 사용 방법, FAQ와 `WebApplication`·`FAQPage` 구조화 데이터를 제공한다.
- 정책 계산은 UI와 분리한 순수 함수로 구현한다.
- 공식 기준과 대조한 Golden Test 2개 이상, 전체 날짜·정책 테스트 15개 이상을 작성한다.
