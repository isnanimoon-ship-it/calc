# SPEC: 군인 월급 계산기

## 목적

복무 형태와 입영일을 입력하면 2026년 병 계급별 봉급을 적용해 표준 복무기간의 예상 봉급,
계급별 수령 내역과 장병내일준비적금 가입 시 예상 만기 자산을 계산한다. 봉급, 본인 적금 납입액,
은행이자, 정부 매칭지원금을 서로 다른 항목으로 보여 `병장 월 205만원`을 매월 현금으로 받는다는
오해를 만들지 않는다.

## v1 지원 범위

- 육군 현역병, 해병대: 표준 18개월
- 해군 현역병: 표준 20개월
- 공군 현역병: 표준 21개월
- 상근예비역: 표준 18개월
- 2026년 봉급표를 적용받는 이등병·일등병·상등병·병장
- 장병내일준비적금 가입 여부, 월 납입액, 납입 개월 수와 예상 은행금리

사회복무요원·대체복무요원은 적금 가입 대상에는 포함될 수 있지만 급여에 식비·교통비 등 별도
구조가 있어 v1 급여 계산에서 제외한다. 장교·준사관·부사관, 후보생, 사관생도도 호봉·수당
계산기가 필요하므로 별도 기능으로 분리한다.

## 입력

1. 기준 연도: v1은 `2026년` 고정, 정책 배지로 표시
2. 복무 형태: 육군 / 해군 / 공군 / 해병대 / 상근예비역
3. 입영일: 필수
4. 계산 범위
   - 전체 복무 예상액
   - 기준일까지 받은 예상 봉급
5. 계산 기준일: 두 번째 모드에서 필수, Asia/Seoul 오늘 기본값
6. 실제 진급일 직접 입력: 선택 고급 설정
   - 일병·상병·병장 진급일
   - 미입력 시 이병 2개월, 일병 6개월, 상병 6개월의 법정 최저복무기간으로 예상
7. 장병내일준비적금: 가입 안 함 / 가입
8. 가입 시 조건부 입력
   - 월 납입액: 5만원 단위, 5만~55만원
   - 납입 개월 수: 기본은 가입 가능한 복무월 전체, 사용자가 축소 가능
   - 예상 연 금리: 기본 5%, 0~20%; 은행별 실제 금리와 다름을 표시

## 결과

### 핵심 결과

- 예상 봉급 총액
- 적금 납입 후 복무 중 사용 가능액: `봉급 합계 - 본인 납입원금`
- 적금 가입 시 예상 만기 자산
- 봉급과 만기 자산을 합친 숫자를 `월급` 또는 `실수령액`으로 표현하지 않는다.

### 계급별 상세

| 계급 | 예상 복무개월 | 월 봉급 | 계급별 봉급 합계 |
|---|---:|---:|---:|
| 이병 | 2개월 | 750,000원 | 계산값 |
| 일병 | 6개월 | 900,000원 | 계산값 |
| 상병 | 6개월 | 1,200,000원 | 계산값 |
| 병장 | 복무형태별 잔여개월 | 1,500,000원 | 계산값 |

- 표준 진급일과 실제 진급일 직접 입력 여부를 표시한다.
- 기준일까지 모드는 완료된 복무월과 현재 진행 중 급여월을 구분한다.
- 실제 월중 입영·전역·진급에 따른 일할 지급은 공식 세부 산식 검증 전에는 계산하지 않는다.
  전체 복무 예상액은 `표준 계급별 복무개월 × 월 봉급`인 계획용 추정치로 명시한다.

### 군적금 상세

- 본인 납입원금
- 예상 은행이자
- 정부 매칭지원금
- 예상 만기수령액
- 월 봉급에서 빠지는 금액은 본인 납입액뿐이며 매칭지원금은 전역·소집해제 후 적격 만기해지 시
  지급된다고 설명한다.
- 중도해지, 미납 회차, 조기전역, 신분전환, 가입자격 미충족은 자동 판정하지 않는다.

## 공유

- 공통 `ShareActions`를 계산 전·후 같은 위치에 둔다.
- Base64URL 상태에는 복무형태, 입영일, 계산범위, 기준일, 진급일, 적금 여부·납입액·개월·금리만 저장한다.
- 복원 시 현재 입력 검증을 통과한 경우에만 자동 계산한다.

## Must Have

- 봉급과 적금 만기자산의 명확한 분리
- 복무형태별 복무기간 및 병장 잔여개월 자동 계산
- 계급별 월 봉급·개월·소계와 총액 검산
- 적금 미가입 시 적금 입력·결과 숨김
- 적금 가입 시 원금 100% 매칭과 이자 추정의 분리
- 입력 변경 시 기존 결과 제거
- 모바일 계급표 카드 전환 또는 안전한 가로 스크롤
- 다크모드 결과 카드 대비, `aria-live="polite"`, 라디오·입력 label

## 범위 밖

- 수당, 일용품비, 휴가비, 성과상여금, 세금·압류·개인 공제
- 월중 입영·진급·전역의 실제 일할 봉급
- 적금 은행별 우대금리 자격과 중도해지 이율
- 과거 연도 봉급과 연도 중 봉급 인상 자동 혼합
- 간부 호봉·수당 및 사회복무요원 실수령액

## 완료 기준

- 2026년 4개 병 계급 봉급이 공식 봉급표와 일치
- 18·20·21개월 유형별 계급개월 합이 전체 복무개월과 일치
- 적금 미가입, 월 5만원, 월 55만원 경계 테스트
- `만기수령액 = 원금 + 예상이자 + 매칭지원금` 불변식
- 전체 자동 테스트와 프로덕션 빌드 통과
