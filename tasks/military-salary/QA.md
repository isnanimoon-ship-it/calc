# QA: 군인 월급 계산기

## 정책·공식

- 이병 750,000원, 일병 900,000원, 상병 1,200,000원, 병장 1,500,000원
- 18개월: 2+6+6+4, 20개월: 2+6+6+6, 21개월: 2+6+6+7
- 계급별 소계 합 = 예상 봉급 총액
- 적금 원금 = 월 납입액 × 납입개월
- 정부 매칭 = 적격 납입원금 100%
- 만기자산 = 원금 + 예상 은행이자 + 매칭지원금
- 복무 중 사용 가능액 = 봉급 총액 - 본인 납입원금

## 경계값

- 납입액 49,999 / 50,000 / 550,000 / 550,001원
- 5만원 배수가 아닌 납입액 거부
- 납입 5 / 6 / 전체 복무개월 / 전체+1개월
- 금리 0 / 5 / 20 / 20.01%
- 입영일, 기준일, 예상 전역일 전후
- 일병·상병·병장 실제 진급일의 누락·역전·범위 이탈
- 월말 28·29·30·31일과 윤년

## UX·표현

- 적금 미가입 시 관련 입력과 만기 결과 미표시
- `월급`, `본인 저축`, `전역 후 지원금`을 한 숫자로 오인하게 표현하지 않음
- 정부지원금을 매월 현금 수령액으로 표시하지 않음
- 예상 은행이자에 `추정` 표시
- 표준 진급 일정과 실제 진급일 차이 안내
- 사회복무요원·간부가 지원되는 것처럼 보이지 않음
- 320px 및 다크모드에서 표·핵심 카드 확인
- 키보드, label, 오류 `role=alert`, 결과 `aria-live`

## 공유·회귀

- 계산 전 URL은 기본 페이지 공유
- 계산 후 Base64URL 복원 결과 동일
- 잘못된 상태는 무시하고 오류를 발생시키지 않음
- 기존 전역일 계산기 정책 변경 회귀 없음
- 전체 테스트, TypeScript, ESLint, production build 통과
