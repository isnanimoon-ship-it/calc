# FORMULA: 주택 취득세 계산기

## 이 문서의 신뢰도에 관한 중요한 사전 고지 (반드시 먼저 읽을 것)

이 계산기는 이 프로젝트에서 법령 의존도가 가장 높은 계산기 중 하나이고(SPEC.md가 이미
`national-pension-benefit-estimate`와 동급으로 규정), 조사 과정에서 SPEC.md 자체의 사실
오류 1건과, 구현 정확도에 직접 영향을 주는 입력 설계 문제 1건을 발견했다. Architect/Builder가
반드시 먼저 읽어야 한다.

1. **[SPEC.md 사실 정정] "지방교육세법"이라는 별도 법률은 존재하지 않는다.** SPEC.md는
   여러 곳에서 "지방세법, 지방세법 시행령, 지방교육세법, 농어촌특별세법"을 나란히 언급해
   지방교육세가 별도 법률에 근거한다고 전제했다. 그러나 이번 조사(law.go.kr 연계 조문 정보,
   여러 독립 검색 결과 교차 확인, 확인일 2026-09-13)에서 **지방교육세는 별도의 "지방교육세법"이
   아니라 「지방세법」제11장(제149조~제151조, 특히 제151조 "과세표준과 세율")에 근거**한다는
   점을 확인했다. 반면 **농어촌특별세는 실제로 별도 법률인 「농어촌특별세법」**이 맞다(casenote.kr
   조문 페이지 직접 로딩 확인). 이 문서와 이후 산출물은 지방교육세 근거 법령명을 **「지방세법」
   제151조**로 통일해서 표기한다.
2. **[입력 설계 문제] SPEC.md가 예시한 "보유 주택 수: 1채/2채/3채 이상"(3구간)으로는
   비조정대상지역의 세율을 정확히 계산할 수 없다.** 아래 "2. 다주택자·조정대상지역 중과세율표"에서
   확정하듯, 다주택자 중과세율은 **조정대상지역에서는 2주택부터, 비조정대상지역에서는 3주택부터**
   중과가 시작되고, 나아가 **비조정대상지역은 3주택(8%)과 4주택 이상(12%)의 세율이 서로 다르다.**
   "3채 이상"을 하나의 버킷으로 묶으면 비조정대상지역 3주택(8%)과 4주택 이상(12%)을 구분할 수
   없어 총 납부액이 최대 수천만원 단위로 틀리는 심각한 오류가 발생한다(아래 검증 예제 13·15
   참고 — 5억원 주택 기준 8% vs 12% 차이가 22,000,000원). **Formula Analyst 권고: "보유 주택
   수" 입력은 최소 4구간(1채/2채/3채/4채 이상)으로 설계해야 한다.** SPEC.md의 해당 문구는
   "예:"로 시작하는 예시였으므로 범위 변경이 아니라 정확도를 위한 구체화로 판단하며, Architect가
   입력 UI를 확정할 때 이 문서의 세율표를 그대로 반영하면 자연히 4구간이 된다.

위 두 가지 모두 아래 본문에서 근거와 함께 상세히 다룬다.

## 목적

「지방세법」제11조(부동산 취득의 세율) 및 제13조의2(법인의 주택 취득 등 중과), 「지방세법」
제151조(지방교육세 과세표준과 세율), 「농어촌특별세법」제4조(비과세)·제5조(과세표준과 세율)에
근거해, 사용자가 입력한 **취득가액(매매가)·전용면적·조정대상지역 해당 여부·취득 후 보유
주택 수** 네 값으로 주택 매매(유상취득) 시의 **취득세·지방교육세·농어촌특별세 및 그 합계
(총 납부액)**를 추정한다. SPEC.md가 확정한 대로 매매(유상취득)·주택·개인(세대 기준) 취득만
다루며, 상속·증여·신축(원시취득)·비주택·법인 취득·감면 제도는 v1에서 계산하지 않는다.

## 입력값

| 변수명 | 설명 | 단위 | 허용 범위 |
|---|---|---|---|
| `acquisitionPrice` (취득가액/매매가) | 과세표준으로 그대로 사용(시가인정액·조정 등 세무서 심사 절차는 반영하지 않음) | 원 (정수) | 필수. `> 0`. 정확한 상·하한은 Builder가 정한다(SPEC "오류와 예외 처리" 참고) |
| `exclusiveArea` (전용면적) | 공급면적이 아닌 전용면적. 국민주택규모(85㎡) 초과 여부 판정에만 사용되며, **취득세·지방교육세 세율 자체에는 영향을 주지 않는다**(아래 "1. 주택 유상취득 표준세율" 확인 사항 참고) | ㎡ (양수, 소수 허용) | 필수. `> 0` |
| `isAdjustmentTargetArea` (조정대상지역 해당 여부) | 사용자 자가 입력(SPEC 확정 — 주소 기반 자동 판정 없음) | boolean | 필수, 기본값 없음(미선택 시 계산 안 함) |
| `houseCountAfterAcquisition` (취득 후 보유 주택 수) | **아래 "사전 고지" 2번에 따라 4구간(1/2/3/4채 이상)으로 설계할 것을 권고** | 정수 구간(1/2/3/4+) | 필수, 기본값 없음 |

### 입력 설계 권고: 왜 3구간이 아니라 4구간인가

- 1채: 조정대상지역 여부와 무관하게 항상 표준세율(가격 구간별 1~3%).
- 2채: 조정대상지역이면 8% 중과, 비조정대상지역이면 표준세율(중과 없음) — **2채 버킷은
  이미 조정 여부에 따라 세율이 갈리므로 "조정대상지역 여부" 입력과 조합해서만 정확히 계산
  가능**(별도 추가 입력 불필요, 기존 두 입력의 조합으로 충분).
- 3채: 조정대상지역이면 12% 중과, 비조정대상지역이면 8% 중과.
- 4채 이상: 조정대상지역·비조정대상지역 모두 12% 중과.

3채와 4채 이상은 **조정대상지역에서는 결과가 같지만(둘 다 12%), 비조정대상지역에서는 다르다
(8% vs 12%)** — 이 비대칭 때문에 "3채 이상"으로 뭉뚱그리면 비조정대상지역 사용자의 결과가
틀린다. 법인은 SPEC Must Have 범위 밖이라 이 구간에 포함하지 않는다.

## 출력값

| 변수명 | 설명 | 단위 |
|---|---|---|
| `priceTier` (가격 구간 판정) | `low`(6억 이하) / `mid`(6억 초과~9억 이하) / `high`(9억 초과) | - |
| `standardRate` (표준세율, 가격 구간별) | 제11조제1항제8호 산정 결과(중과 여부와 무관하게 항상 계산해 근거 화면에 표시) | 소수(예 0.01) |
| `isHeavyRateApplied` (중과세율 적용 여부) | 조정대상지역×보유주택수 조합으로 판정 | boolean |
| `appliedRate` (실제 적용된 취득세율) | 중과 대상이면 0.08/0.12, 아니면 `standardRate` | 소수 |
| `acquisitionTax` (취득세액) | `acquisitionPrice × appliedRate`, 10원 미만 절사 후 | 원 |
| `localEducationTax` (지방교육세액) | 아래 "3. 지방교육세율" 산식, 10원 미만 절사 후 | 원 |
| `isRuralSpecialTaxExempt` (농어촌특별세 비과세 여부) | `exclusiveArea <= 85` | boolean |
| `ruralSpecialTax` (농어촌특별세액) | 비과세가 아니면 아래 "4. 농어촌특별세율" 산식, 10원 미만 절사 후. 비과세면 0 | 원 |
| `totalTax` (총 납부액) | `acquisitionTax + localEducationTax + ruralSpecialTax` | 원 |

## 공식

### 1. 주택 유상취득 표준세율 — 「지방세법」제11조제1항제8호

**법적 근거**: 「지방세법」제11조제1항제8호(casenote.kr 조문 페이지·law.go.kr 연계 정보,
확인일 2026-09-13). 시행일 2020-08-12(2020년 7·10대책 후속 지방세법 개정, 법률
제17473호) 이후 현재(2026-09-13)까지 이 가격 구간·산식 자체는 변경되지 않았다(2026년 개정
지방세법·지방세특례제한법 검토 결과, 표준세율 구간 변경 없음 — 아래 "5. 2026년 현재 시점
재확인" 참고).

| 구간(취득당시가액) | 세율 | 근거 |
|---|---|---|
| 6억원 이하 | 1,000분의 10 (1%) | 제11조제1항제8호가목 |
| 6억원 초과 ~ 9억원 이하 | 아래 계산식 | 제11조제1항제8호나목 |
| 9억원 초과 | 1,000분의 30 (3%) | 제11조제1항제8호다목 |

**6억 초과~9억 이하 구간 계산식(나목, 원문 확인)**:

```
세율 = ( 취득당시가액 ÷ 300,000,000 × 2 − 3 ) × 1/100
```

- "취득당시가액"은 원 단위 그 자체를 대입한다(예: 7.5억원 → 750,000,000).
- **소수점 처리(법 명시)**: "소수점 이하 다섯째자리에서 반올림하여 소수점 넷째자리까지
  계산한다." 즉 세율을 소수(예 0.0166667) 형태로 계산한 뒤, 5번째 소수 자리에서 반올림해
  4번째 자리까지 남긴다(예: 0.0166667 → 0.0167).
- 검증(경계 연속성): 6억원 대입 시 6×2/3−3=1.0000(=1%, 가목과 연속), 9억원 대입 시
  9×2/3−3=3.0000(=3%, 다목과 연속) — 구간 경계에서 끊기지 않고 이어짐을 자체 검산으로
  확인했다.
- 예시(자체 계산, 위 공식 직접 대입 — 아래 "검증 예제" 4·17번과 동일):
  - 7억원 → (7/3×2−3)=1.66667 → 반올림 1.6667% (자체 계산 결과이며, 별도로 여러 독립
    검색 결과에서도 "7억원 약 1.67%"로 반복 인용되어 정합성을 재확인했다)
  - 7.5억원 → 정확히 2.0000%
  - 8억원 → (8/3×2−3)=2.33333 → 반올림 2.3333%(독립 검색 결과의 "8억원 약 2.33%"와 일치)

**전용면적 85㎡ 초과 여부에 따른 취득세율 자체의 차등**: **없음.** 제11조제1항제8호는
가격에만 의존하며, 85㎡ 기준은 오직 아래 "4. 농어촌특별세"의 비과세 판정에만 쓰인다(자주
혼동되는 지점이라 SPEC.md도 명시적으로 확인을 요구했다 — 명확히 "없다"로 확정).

### 2. 다주택자·조정대상지역 중과세율표 — 「지방세법」제13조의2

**법적 근거**: 「지방세법」제13조의2(법인의 주택 취득 등 중과), 시행일 2020-08-12(법률
제17473호, 2020년 7·10대책 후속 개정). 산식 원문(casenote.kr·law.go.kr 연계 정보 교차
확인, 확인일 2026-09-13):

> 제11조제1항제7호나목의 세율(=4%, 주택 외 부동산 유상취득 표준세율)을 "표준세율"로 하여
> 해당 세율에 중과기준세율(2%)의 100분의 200 또는 100분의 400을 합한 세율을 적용한다.

이 산식이 **왜 가격 구간(1~3%)과 무관하게 8%·12% 정액이 되는지**: 산식이 참조하는
"표준세율"은 주택 가격별 세율(제8호, 1~3%)이 아니라 **고정된 제7호나목 세율(4%)**이기
때문이다. 8% = 4%(제7호나목) + 4%p(중과기준세율 2%×200%), 12% = 4% + 8%(중과기준세율
2%×400%). 이 구조를 정확히 이해해야 아래 지방교육세·농어촌특별세 계산에서 "왜 표준세율
사례와 계산 방식이 다른지"가 설명된다.

**확정 세율표(개인, 조정대상지역 여부 × 취득 후 보유 주택 수)**:

| 보유 주택 수 | 조정대상지역 | 비조정대상지역 |
|---|---|---|
| 1채 | 표준세율(1~3%, 위 1번 표) | 표준세율(1~3%) |
| 2채 | **8%** | 표준세율(1~3%, 중과 없음) |
| 3채 | **12%** | **8%** |
| 4채 이상 | **12%** | **12%** |
| 법인(참고, Should Have 판단용) | **12%**(주택 수·지역 무관 일괄) | **12%** |

- "일시적 2주택"(대통령령으로 정하는 요건 충족 시 2주택이라도 중과 제외)이 법 조문상
  명시적으로 존재하나, **이 계산기 v1은 이 예외를 판정하지 않는다**(SPEC Must Have가
  "보유 주택 수" 외에 일시적 2주택 여부를 입력받지 않기로 확정). 즉 2채를 선택하면 항상
  위 표대로 계산하며, 실제로 일시적 2주택 특례 대상이라면 이 계산기의 결과가 실제보다
  과대 추정된다는 점을 결과 화면에 반드시 고지해야 한다(아래 "예외" 참고).

**[2022~2025년 완화 논의의 실제 시행 여부 — 반드시 확인 필요했던 항목]**: 조사 결과,
**8%/12% 중과세율 자체를 낮추는 지방세법 개정은 확인 시점(2026-09-13)까지 시행되지
않았다.**
- 2025년 4월 국무회의를 통과한 것은 "지방세법 시행령" 개정으로, **다주택자·법인 중과세율
  적용이 '제외'되는 지방의 저가주택 기준을 공시가격 1억원 → 2억원으로 완화**한 것이다
  (2025-01-02 이후 취득분 소급 적용, 행정안전부 보도자료 "지방 저가주택 취득세 중과 기준
  완화" 확인). 이는 **저가주택 특례 대상의 범위를 넓힌 것**이지, 8%·12% 세율 자체를
  낮춘 것이 아니다. 이 저가주택 특례(수도권 외 지역, 공시가격 2억원 이하)는 SPEC.md가
  확정한 v1 입력(취득가액·전용면적·조정대상지역·보유 주택 수)만으로는 판정할 수 없는
  추가 조건(공시가격, 소재지의 수도권 여부)이 필요해 **v1에서는 반영하지 않고, 이 사실을
  결과 화면 고지 문구에 포함할 것을 권고**한다(아래 "예외" 참고).
- 2026년 7월 31일자 세제개편안 보도(2026 세제개편)의 "다주택자 중과 한시 완화"는
  **양도소득세**(조정대상지역 다주택자 양도 시 중과세율을 2028년까지 한시적으로 5~15%p로
  인하)에 관한 것으로, **취득세 8%/12% 중과세율과는 무관**함을 직접 기사 본문 확인으로
  검증했다(2026-08-03자 파이낸셜뉴스 기사, WebFetch 직접 확인).
- 2025년 12월 30일 국회를 통과해 2026년 시행된 개정 지방세법·지방세특례제한법(2026-01-01,
  일부 2026-07-01·2027-01-01 시행)의 주요 개정 내용(지방 준공 후 미분양 감면 신설, 인구감소
  지역 세컨드홈 특례 확대, 배우자·직계존비속 간 유상거래 시가 판정 기준 등)에도 **8%/12%
  중과세율 자체나 1~3% 표준세율 구간의 변경은 포함되지 않았다**(법률사무소 뉴스레터 요약
  직접 확인, 확인일 2026-09-13).
- **결론: 2026-09-13 현재 시행 중인 다주택자·조정대상지역 중과세율은 위 표(8%/12%,
  2020-08-12 시행)가 최신이며, 이를 채택한다.** 다만 정치적으로 이 세율을 낮추는 방안이
  반복적으로 논의되어 온 만큼(위 세제개편안 등), **차기 정기 재검토(2027-01-01) 전이라도
  다주택자 취득세 중과 완화 관련 지방세법 개정안이 국회 본회의를 통과·공포되면 즉시
  재검토가 필요하다**(아래 "기준/출처" 조기 재검토 트리거 참고).

### 3. 지방교육세율 — 「지방세법」제151조

**법적 근거**: 「지방세법」제151조제1항제1호(과세표준과 세율), 시행 2026-01-01(법률
제21308호, 2025-12-31 일부개정 반영본, 확인일 2026-09-13). 원문 취지:

- **가목(제11조제1항제8호 표준세율이 적용되는 경우, 즉 중과 대상이 아닌 경우)**:
  "해당 세율에 100분의 50을 곱한 세율을 적용하여 산출한 금액의 100분의 20"
  → `지방교육세 = 취득가액 × (표준세율 × 0.5) × 0.2 = 취득가액 × 표준세율 × 0.1`
  = **취득세액의 10%**와 정확히 같다(0.5×0.2=0.1이므로 "취득가액×표준세율"=취득세액에
  0.1을 곱한 것과 동일).
- **나목(제13조의2 중과세율이 적용되는 경우)**: "제11조제1항제7호나목의 세율(4%)에서
  중과기준세율(2%)을 뺀 세율을 적용하여 산출한 금액의 100분의 20"
  → `지방교육세 = 취득가액 × (4% − 2%) × 0.2 = 취득가액 × 2% × 0.2 = 취득가액 × 0.4%`
  **취득세 중과세율이 8%든 12%든 상관없이 항상 0.4%로 고정**된다(가감산 항인 "중과기준세율의
  200%/400%" 부분은 이 산식에 반영되지 않기 때문). 이는 여러 독립된 2차 출처(부동산 세금
  계산 안내 자료)가 공통으로 서술하는 "다주택자 중과 시 지방교육세는 세율과 무관하게
  0.4%"와 정확히 일치해 교차 확인했다(확인일 2026-09-13).

**정리**:

| 구분 | 지방교육세율(취득가액 대비) |
|---|---|
| 표준세율(6억 이하, 1%) | 0.1% |
| 표준세율(6~9억, 계산식 r%) | r% × 0.1 |
| 표준세율(9억 초과, 3%) | 0.3% |
| 중과세율(8% 또는 12%, 조정/비조정 무관) | **0.4% (고정)** |

### 4. 농어촌특별세율과 국민주택규모(85㎡) 비과세 기준

**비과세 근거**: 「농어촌특별세법」제4조(비과세) 및 관련 시행령 — 전용면적 85㎡ 이하
(국민주택규모) 주택의 취득에는 농어촌특별세를 부과하지 않는다(다수 독립 출처 교차 확인,
casenote.kr 조문 페이지 직접 로딩 확인, 확인일 2026-09-13).
- **[V1 단순화, 확인 필요로 별도 표시]** 국민주택규모의 법정 정의(「주택법 시행령」 등)는
  원칙적으로 85㎡ 이하이나, **수도권을 제외한 도시지역이 아닌 읍·면 지역**은 100㎡ 이하까지
  국민주택규모로 인정하는 지역 특례가 있다고 알려져 있다 — 이 특례를 이번 세션에서 1차
  출처로 재확인하지는 못했다(**확인 필요**). SPEC.md의 입력 설계(전용면적만 입력받고
  지역/읍면 여부는 입력받지 않음)를 그대로 따르는 한, v1은 **전국 공통 85㎡ 단일 기준**만
  적용하고, 읍·면 지역 100㎡ 특례는 반영하지 않는다는 점을 결과 화면에 명시할 것을 권고한다.

**과세표준과 세율 근거**: 「농어촌특별세법」제5조제1항제6호(casenote.kr 조문 페이지 원문
직접 확인, 확인일 2026-09-13):

> "「지방세법」제11조 및 제12조의 표준세율을 100분의 2로 적용하여 「지방세법」·「지방세특례
> 제한법」및「조세특례제한법」에 따라 산출한 취득세액"을 과세표준으로 하여 세율 100분의 10

**표준세율 적용 시(중과 아님)**: 이 항목은 실제 가격별 표준세율(1~3%)이 아니라 **"2%로
가정한" 취득세액**을 과세표준으로 삼는다. 즉 `농어촌특별세 = 취득가액 × 2% × 10% =
취득가액 × 0.2%` — **가격 구간(1%/계산식/3%)과 무관하게 항상 0.2% 고정**이다.

**중과세율 적용 시(제13조의2)**: 위 제5조제1항제6호는 문언상 "제11조 및 제12조의 표준세율을
2%로 적용"만 언급하고 제13조의2를 별도로 규정하지 않는다. 그러나 제13조의2의 세율 자체가
"표준세율(제7호나목, 4%) + 중과기준세율의 200%/400%"로 구성되므로, 농특세 계산에서도
"표준세율 부분만 2%로 치환하고, 중과 가산분(200%/400%)은 그대로 반영"하는 구조가 된다:

```
8% 중과: 농특세 과세표준 세율 = 2%(치환) + 4%p(중과기준세율 2%×200%) = 6% → ×10% = 0.6%
12% 중과: 농특세 과세표준 세율 = 2%(치환) + 8%p(중과기준세율 2%×400%) = 10% → ×10% = 1.0%
```

이 산출 방식은 (a) 위 법령 문언의 논리적 재구성과 (b) 최소 3개의 독립된 검색 결과가
동일한 수치(8% 중과 시 0.6%, 12% 중과 시 1.0%)를 일관되게 제시한다는 점, (c) 이렇게 나온
"취득세+지방교육세+농특세" 합계가 "8% 중과·85㎡초과 = 9.0%", "12% 중과·85㎡초과 = 13.4%"라는,
한국 부동산 세금 설명 자료에서 매우 널리 반복 인용되는 잘 알려진 벤치마크 수치와 **정확히
일치**한다는 점으로 교차 검증했다(확인일 2026-09-13). **법 조문의 문언 자체가 제13조의2를
명시하지 않아 100% 조문 직접 인용은 아니지만("부분 확인"), 정황·수치 일치도가 매우 높아
신뢰도가 높다고 판단한다.**

**정리(85㎡ 초과 시에만 부과, 이하는 전액 비과세)**:

| 구분 | 농어촌특별세율(취득가액 대비, 85㎡ 초과 시) |
|---|---|
| 표준세율(가격 구간 무관) | 0.2% |
| 8% 중과 | 0.6% |
| 12% 중과 | 1.0% |
| 85㎡ 이하 | 0원(비과세, 세율 무관) |

- 경기: 과천시, 광명시, 성남시(분당구·수정구·중원구), 수원시(영통구·장안구·팔달구),

## 계산 순서

1. **입력 검증**: `acquisitionPrice > 0`, `exclusiveArea > 0`, `isAdjustmentTargetArea`
   선택 여부, `houseCountAfterAcquisition` 선택 여부(미선택 시 계산하지 않음, SPEC Must
   Have).
2. **가격 구간 판정 및 표준세율 산출**: `acquisitionPrice`를 6억/9억과 비교해 `priceTier`
   판정. `mid` 구간이면 위 "1. 주택 유상취득 표준세율" 계산식으로 `standardRate`를 소수
   4자리까지 산출(5번째 자리 반올림). `low`/`high`는 각각 0.01/0.03 고정.
3. **중과 대상 여부 판정**: `isAdjustmentTargetArea` × `houseCountAfterAcquisition` 조합을
   위 "2. 다주택자·조정대상지역 중과세율표"에 대입해 `isHeavyRateApplied`와 (해당 시)
   중과세율(0.08/0.12)을 결정한다.
4. **적용 세율 확정**: 중과 대상이면 `appliedRate = 0.08` 또는 `0.12`, 아니면
   `appliedRate = standardRate`.
5. **취득세 산출**: `acquisitionTaxRaw = acquisitionPrice × appliedRate`(완전정밀도 유지).
6. **지방교육세 산출**: 표준세율 케이스면 `localEducationTaxRaw = acquisitionTaxRaw × 0.1`,
   중과 케이스면 `localEducationTaxRaw = acquisitionPrice × 0.004`(항상 0.4% 고정, 8%/12%
   무관).
7. **농어촌특별세 산출**: `exclusiveArea <= 85`이면 `isRuralSpecialTaxExempt = true`,
   `ruralSpecialTax = 0`. 초과면 `isRuralSpecialTaxExempt = false`이고, 표준세율 케이스는
   `ruralSpecialTaxRaw = acquisitionPrice × 0.002`, 8% 중과는 `× 0.006`, 12% 중과는
   `× 0.01`.
8. **10원 미만 절사(각 세목 독립 1회)**: `acquisitionTax = floor(acquisitionTaxRaw/10)*10`,
   `localEducationTax = floor(localEducationTaxRaw/10)*10`,
   `ruralSpecialTax = floor(ruralSpecialTaxRaw/10)*10`(0원인 경우는 그대로 0). 근거는 아래
   "정밀도/반올림 정책" 참고.
9. **총 납부액 합산**: `totalTax = acquisitionTax + localEducationTax + ruralSpecialTax`
   (절사된 값들의 합, 합계 자체를 다시 절사하지 않음).
10. **계산 근거 구성**: `priceTier`, `standardRate`, `isHeavyRateApplied`, `appliedRate`,
    `isRuralSpecialTaxExempt`를 모두 결과 화면 근거 영역에 노출한다(SPEC Must Have —
    "적용된 세율이 표준세율인지 다주택자 중과세율인지").
11. **정책 고지 문구 표시**: (a) 일시적 2주택 특례 미반영, (b) 지방 저가주택(공시가격
    2억원 이하) 중과 제외 특례 미반영, (c) 생애최초 등 감면 미반영, (d) 조정대상지역은
    사용자 자가 확인 책임, (e) 읍·면 지역 국민주택규모 100㎡ 특례 미반영(확인 필요 항목)을
    함께 표시한다.

## 단위

- 금액: 원 단위 정수. 내부 계산(5~7단계)은 완전정밀도(부동소수점 `Number`로 충분 — 이
  계산기가 다루는 금액 범위는 안전 정수 범위에 전혀 근접하지 않는다) 유지, 10원 미만 절사는
  8단계에서 세목별로 각 1회만 수행한다.
- 세율: 무차원 소수로 내부 저장(예 0.01, 0.08), 표시만 %.
- 면적: ㎡, 소수 허용(등기부등본 표기 관례상 소수 둘째 자리까지 흔함 — Builder가 표시 형식
  결정).
- 취득세 6~9억 구간 세율의 "소수점 넷째자리까지" 규정은 **세율 자체(소수, 예 0.0167)**를
  가리키며, 최종 취득세액(원)에 적용하는 규정이 아니다 — 순서를 반드시 "세율을 먼저 4자리로
  확정 → 그 세율을 가격에 곱함"으로 지켜야 한다(반대 순서로 하면 결과가 미세하게 달라짐).

## 정밀도 / 반올림 정책

- **내부 계산**: 세율 계산(6~9억 구간)까지는 법정 반올림 규칙(5번째 소수 자리 반올림, 4자리
  확정)을 따르고, 그 이후 세액 계산(가격×세율)은 절사 전까지 완전정밀도로 유지한다.
- **최종 표시 단계에서 세목별 10원 미만 절사(내림) 1회 적용**:
  `acquisitionTax`, `localEducationTax`, `ruralSpecialTax` 각각 독립적으로
  `Math.floor(raw/10)*10`. 절사된 값을 서로의 계산이나 총합 계산 외 다른 계산에 재사용하지
  않는다(중간 절사 금지 원칙, `national-pension-benefit-estimate` FORMULA.md와 동일한
  원칙).
- **법적 근거와 잔여 불확실성**: 「지방세기본법」제59조("끝수 계산에 관한 「국고금 관리법」의
  준용" — casenote.kr·검색 교차 확인, 확인일 2026-09-13)가 "지방자치단체의 징수금의 끝수
  계산에 관하여는 「국고금 관리법」제47조를 준용한다"고 규정하고, 「국고금 관리법」제47조
  제1항은 "국고금의 수입 또는 지출에서 **10원 미만**의 끝수가 있을 때에는 그 끝수는 계산하지
  아니하고, 전액이 10원 미만일 때에도 그 전액을 계산하지 아니한다"고 규정한다. 다만
  같은 조 제2항은 "국세의 **과세표준액** 산정 시 **1원 미만**"이라는 별도 기준을 두고 있어,
  취득세·지방교육세·농어촌특별세 산출 세액에 정확히 몇 항이 적용되는지(10원 단위 절사인지,
  더 세밀한 단계에서 1원 단위 절사가 먼저 적용된 뒤 10원 단위가 다시 적용되는지)를 **1차
  출처 원문 대조로 완전히 확정하지 못했다(확인 필요)**. `national-pension-benefit-estimate`
  선례에서 이미 동일한 조항(제47조제1항)이 국민연금 라이브 계산기와 21/21 실증 일치한
  전례가 있어 "10원 미만 절사"를 잠정 채택하지만, **Calculation Auditor가 위택스
  (wetax.go.kr) 모의계산 결과와 직접 대조해 확정할 것을 권고한다.**
- **표시 형식**: `Intl.NumberFormat('ko-KR')` 등으로 천 단위 콤마 표시(docs/CALCULATOR_RULES.md
  공통 규칙).

## 예외

- **`acquisitionPrice`가 0 이하, 숫자가 아님, 빈 값**: 계산하지 않고 오류 표시(SPEC Must
  Have).
- **`exclusiveArea`가 0 이하, 숫자가 아님, 빈 값**: 계산하지 않고 오류 표시.
- **`isAdjustmentTargetArea`·`houseCountAfterAcquisition` 미선택**: 추정 기본값으로 계산하지
  않고 오류 표시(SPEC Must Have — "선택하지 않으면 계산하지 않는다").
- **`acquisitionPrice`가 정확히 6억원**: 가목(1%) 적용(가목이 "이하"를 포함).
- **`acquisitionPrice`가 정확히 9억원**: 나목(계산식) 적용(나목이 "이하"를 포함) — 다만
  계산식이 정확히 3%를 산출하므로 다목과 수치상 차이는 없다. 구간 판정 로직(어느 목이
  적용됐는지 근거 표시)에서는 나목으로 표시해야 한다.
- **`exclusiveArea`가 정확히 85㎡**: 농어촌특별세 비과세(법 문언이 "이하"). 85.01㎡부터
  과세 대상.
- **일시적 2주택 특례 대상 사용자**: v1은 이 예외를 판정하지 않는다. "2채"를 선택하면
  조정대상지역 여부에 따라 항상 표준세율 또는 8% 중과로 계산하며, 실제로 종전 주택을
  일정 기한 내 처분할 계획이 있는 사용자에게는 **결과가 실제보다 과대 추정**될 수 있음을
  고지해야 한다.
- **지방 저가주택(공시가격 2억원 이하, 수도권 외) 중과 제외 특례 대상 사용자**: v1은
  공시가격·소재지(수도권 여부)를 입력받지 않으므로 이 특례를 판정하지 않는다. 다주택자가
  비수도권 저가주택을 취득후 보유주택 수 2채 이상으로 계산하면 **결과가 실제보다 과대
  추정**될 수 있음을 고지해야 한다.
- **법인 취득**: v1 입력 모델 자체가 개인(세대 기준)을 전제하므로 법인 취득에는 이 계산기를
  쓸 수 없다는 점을 명시한다(SPEC Must Have).
- **감면(생애최초 등) 대상 사용자**: 결과는 감면 미반영 기준이며 실제보다 과대 추정될 수
  있음을 고지한다(SPEC Must Have).

## 검증 예제 (Golden Test, 17개 — SPEC 최소 요건 10개 이상 충족)

> **대조 방법 고지**: 아래 예제는 모두 위에서 확정한 법령 산식(지방세법 제11조·제13조의2·
> 제151조, 농어촌특별세법 제5조)을 Formula Analyst가 직접 대입해 계산한 값이다. 이 세션에는
> wetax.go.kr 등 실제 계산기에 값을 입력해 서버 응답을 받는 대화형 도구가 주어지지 않아
> (WebFetch는 정적 페이지만 읽을 수 있고, 계산기 자체는 JS 동적 렌더링), **"위택스 계산기에
> 실제로 입력해 얻은 결과"를 인용하지는 않았다** — 확인 없이 외부 계산기 결과를 베끼는 것을
> 피하기 위해서다(사전 지시사항 참고). 대신 예제 12·14는 **법령 문언을 재구성해 도출한
> 총부담률(9.0%, 13.4%)이 한국 부동산 세금 설명 자료에서 반복적으로 인용되는 잘 알려진
> 벤치마크와 정확히 일치**함을 최소 3개의 독립 검색 결과로 교차 확인해 "공식 계산기 결과
> 또는 법령 조문의 계산 예시와 대조"라는 SPEC 요건을 충족한다(확인일 2026-09-13). 나머지
> 예제도 모두 확정된 법령 산식의 기계적 대입이므로 Calculation Auditor가 동일 산식으로

- `appliedRate=0.12`
- **Expected: 취득세 60,000,000 / 지방교육세 2,000,000 / 농특세 5,000,000 / 총
  67,000,000원**(예제13의 "4채 이상" 결과와 완전히 동일해야 함 — 합계 세율 13.4% =
  500,000,000×0.134, 마찬가지로 널리 인용되는 벤치마크와 일치, 최소 3개 독립 검색 결과로
  교차 확인)

### 예제 15 — 표준세율 대 중과세율 배수 비교(SPEC 요구 사항)
- 조정·1주택, 5억원, 59㎡(예제9와 동일): 총 5,500,000원
- 조정·3주택 이상, 5억원, 59㎡(85㎡ 이하이므로 농특세 0): `acquisitionTax=60,000,000`,
  `localEducationTax=2,000,000`, `ruralSpecialTax=0` → 총 62,000,000원
- **배수: 62,000,000 ÷ 5,500,000 ≈ 11.27배** — 같은 5억원 주택이라도 조정대상지역 3주택
  이상이면 총 납부액이 약 11.3배로 뛴다는 것을 보여주는 SPEC 필수 대조 케이스(취득세만
  비교하면 정확히 12배: 60,000,000÷5,000,000=12).

### 예제 16 — 6~9억 구간 추가 검증(8억원)
- Input: `acquisitionPrice=800,000,000`, `exclusiveArea=100`, `isAdjustmentTargetArea=false`, `houseCountAfterAcquisition=1`
- `standardRate = (800,000,000/300,000,000×2−3)×1/100 = (5.33333−3)×1/100 = 0.0233333 → 반올림 0.0233`
- `acquisitionTax = 18,640,000`, `localEducationTax = 1,864,000`, `ruralSpecialTax = 1,600,000`
- **Expected: 취득세 18,640,000 / 지방교육세 1,864,000 / 농특세 1,600,000 / 총 22,104,000원**

### 예제 17 — 10원 미만 절사 규칙 검증(잠정, 확인 필요 — 위 "정밀도/반올림 정책" 참고)

### 상속·증여로 인한 취득세 계산 — **승격하지 않음(계속 Should Have, 미확정 잔여 항목 있음)**

  - 세간에 알려진 "1가구 1주택자가 상속으로 주택을 취득하는 경우 0.8% 특례세율"의 정확한
