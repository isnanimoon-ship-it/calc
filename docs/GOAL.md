# 프로젝트 목표

온라인 계산기 모음 사이트. 계산기 개수를 늘리는 것 자체가 목표가 아니라, 계산기 하나하나의 정확성과 완성도를 역할별 검증으로 담보하는 것이 목표다.

## 핵심 목표
1. 계산 결과의 정확성 — 법령/공식 문서에 근거, 확인 안 된 수치는 절대 추정하지 않음
2. 일반 사용자가 계산법을 몰라도 쓸 수 있는 UI
3. 모바일 사용성 (320px~1440px 대응)
4. 입력 오류·극단값에 대한 안전성
5. 계산 근거를 이해할 수 있는 결과 설명 (수식 breakdown)
6. 계산기 간 일관된 디자인
7. 검색 유입을 고려한 페이지 구조
8. 확장 가능한 공통 계산기 아키텍처

## 목표를 어떻게 측정하는가
각 목표는 [docs/EVALUATION.md](EVALUATION.md)의 100점 평가 배점(계산 정확성 35, 예외/경계값 15, UX 15, 모바일 10, 접근성 5, 성능 5, 설명/근거 5, SEO 5, 코드품질 5)에 대응한다. 목표는 선언에 그치지 않고 계산기마다 채점된다.

## 계산기 예시 (확장 목록, 고정 아님)
퍼센트, 할인율, 날짜, 나이, BMI, 대출 이자, 예금/적금, 복리, 부가세, 단위 변환, 연봉/월급, 기타 생활 계산기 등. 세부 우선순위와 범위 결정은 [docs/PRODUCT.md](PRODUCT.md)를 따른다.
