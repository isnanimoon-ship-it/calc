# 스펙: 퇴직금 계산기

- slug: `severance-pay`
- category: `labor`
- 목적: 근로자퇴직급여 보장법상 법정 퇴직금(중간정산·DC/DB형 등 특수 케이스 제외, 순수 법정 퇴직금)을 계산한다.
- 이 계산기는 연도별 `rates-{year}.json`을 참조하지 않는다 (최저임금·요율이 아니라 법 조항 자체가 계산 변수이기 때문). 단, 근거 법령 조항이 개정되면 이 문서와 로직을 함께 갱신한다.

## 0. 지급 대상 요건 (계산 전 선행 체크)
아래 두 조건을 **모두** 충족해야 법정 퇴직금 지급 대상이다. 하나라도 미충족 시 계산 결과 대신 안내 문구를 표시하고 금액을 계산하지 않는다.
1. 계속근로기간 1년 이상
2. 4주간을 평균하여 1주간의 소정근로시간 15시간 이상

근거: 근로자퇴직급여 보장법 제4조 제1항

## 1. 입력값
| 필드 | 타입 | 필수 | 설명 |
|---|---|---|---|
| 입사일 | date | 필수 | |
| 퇴사일 | date | 필수 | "퇴사일 = 근로관계 종료일(마지막 근무일의 다음날)" 기준으로 안내 문구 표기. 재직일수 = 퇴사일 − 입사일 |
| 주당 소정근로시간 | number(시간) | 필수 | 0번 요건 판정용 |
| 평균임금 산정 제외기간 (선택, 복수 입력 가능) | {시작일, 종료일, 사유} | 선택 | 수습(개시 후 3개월 이내), 사용자 귀책 휴업, 출산전후휴가, 업무상 재해 휴업, 육아휴직 등. 평균임금 산정기간의 총일수와 그 기간 임금에서 각각 차감 |
| 퇴사일 이전 3개월간 지급된 임금총액 | 원 | 필수 (아래 A/B 중 택1 방식) | 기본급+제수당 등 통화로 지급된 임금(임시 지급 임금·현물 지급 제외) |
| 퇴사일 이전 12개월간 지급된 상여금 총액 | 원 | 선택(기본 0) | |
| 퇴사일 이전 12개월간 지급된 연차수당 총액 | 원 | 선택(기본 0) | |
| 1일 통상임금 | 원 | 선택 | 입력 시 평균임금과 비교해 더 큰 값을 사용 |

**입력 방식 A/B (구현 시 결정 필요, 우선 A로 설계 권장):**
- A(간편 모드): 3개월 임금총액을 사용자가 직접 한 번에 입력
- B(상세 모드): 월별 기본급 + 기타수당을 입력받아 자동 합산 (고용노동부 계산기 방식과 동일, 추후 v2로 확장 권장)

## 2. 계산 공식 (단계별)
1. **재직일수** = 퇴사일 − 입사일 (일 단위, 근무제외기간이 있으면 그만큼 추가 차감)
2. **평균임금 산정기간 총일수** = 퇴사일 이전 3개월의 총 달력일수 − 제외기간 일수
3. **3개월 임금총액(제외기간 임금 차감 후)** = 입력받은 3개월 임금총액 − 제외기간 중 지급된 임금
4. **상여금 가산액** = 연간 상여금 총액 × 3/12
5. **연차수당 가산액** = 연간 연차수당 총액 × 3/12
6. **1일 평균임금(전 단위까지 보존)** = (3의 값 + 4 + 5) ÷ 2의 값
7. **기준임금 확정** = max(1일 평균임금, 1일 통상임금) — 통상임금 미입력 시 1일 평균임금만 사용
8. **퇴직금** = 기준임금 × 30 × (재직일수 ÷ 365), 최종 결과만 원 단위로 반올림

### 금액 정밀도 관련 결정 (CLAUDE.md 보완 필요 사항)
공식 계산 방식상 1일 평균임금은 원 미만 단위("전", 1/100원)까지 계산되어야 공식 계산기와 일치한다. 따라서 이 계산기는 CLAUDE.md의 "원 단위 정수 연산" 원칙을 다음과 같이 적용한다:
- 6번 단계까지는 **"전" 단위 정수**(정수 × 100)로 계산해 부동소수점 오차를 막는다.
- 최종 8번 결과만 원 단위로 반올림해 사용자에게 표시한다.
- 반올림 방식(사사오입/절사)은 법적으로 강제된 규정을 찾지 못함 → **확인 필요**. 우선 사사오입(반올림)으로 구현하고 주석에 "확인 필요"로 표시.

## 3. 계산 근거 화면 노출안 (UI breakdown)
```
1일 평균임금 = (3개월 임금총액 + 상여금×3/12 + 연차수당×3/12) ÷ 산정기간 총일수
            = (7,080,000원 + 250,000원 + 18,750원) ÷ 92일
            = 88,641.31원

기준임금 = max(1일 평균임금 88,641.31원, 1일 통상임금 XX원) = 88,641.31원

퇴직금 = 기준임금 × 30일 × (재직일수 1,080일 ÷ 365일)
      = 7,868,433원
```
각 줄에 근거 라벨(예: "근로기준법 제2조 제1항 제6호")을 함께 표기한다.

## 4. 예외 케이스
- 근속 1년 미만 → 지급대상 아님 안내, 계산 중단
- 소정근로시간 4주 평균 15시간 미만 → 지급대상 아님 안내, 계산 중단
- 제외기간이 3개월 산정기간을 전부 덮어 총일수가 0 이하가 되는 경우 → 에러 처리 필요 (**확인 필요**: 이 경우 근로기준법 시행령상 별도 산정 특례가 있는지 추가 확인 필요)
- 상여금/연차수당 미입력 → 0원으로 처리, 정상 계산
- 1일 통상임금 미입력 → 통상임금 비교 단계 생략, 결과 화면에 "통상임금 비교 미적용" 명시
- 합병/영업양도 등으로 근속기간 승계 여부 판단 → 이 계산기 범위 밖. 단순 "입력된 입사일~퇴사일" 기준으로만 계산한다는 점을 안내 문구에 명시

## 5. 근거 법령
- 근로자퇴직급여 보장법 제4조(퇴직급여제도의 설정) — 지급요건
- 근로자퇴직급여 보장법 제8조(퇴직금제도의 설정 등) — 계속근로기간 1년에 대해 30일분 평균임금
- 근로자퇴직급여 보장법 제9조(퇴직금의 지급 등) — 지급사유 발생일부터 14일 이내 지급 (정책 안내 문구용)
- 근로기준법 제2조 제1항 제6호 — 평균임금 정의(사유 발생일 이전 3개월간 임금총액 ÷ 총일수)
- 근로기준법 제2조 제2항 — 산출된 평균임금이 통상임금보다 적으면 통상임금을 평균임금으로 함
- 근로기준법 시행령 제2조 — 평균임금 산정에서 제외되는 기간과 임금(수습 3개월 이내, 사용자 귀책 휴업, 출산전후휴가, 업무상 재해 휴업, 육아휴직 등)
- 상여금·연차수당의 3/12 가산 방식 — **확인 필요**: 명문 조항이 아니라 행정해석·판례에 기반한 실무 관행으로 파악됨. 구현 전 정확한 근거(고용노동부 행정해석 번호 또는 대법원 판례번호)를 재확인해 코드 주석에 명시할 것.

## 6. 정책 안내 문구 (결과 화면 하단)
> 이 계산기는 근로자퇴직급여 보장법 및 근로기준법(평균임금 산정)을 기준으로 하며, 실제 지급액과 차이가 있을 수 있습니다. 정확한 금액은 사업장 담당자 또는 고용노동부에 확인하시기 바랍니다.

## 7. 테스트 케이스
1. **고용노동부 노동포털 예시(공식, 일부)** — 출처: moel.go.kr 퇴직금 계산 안내 페이지
   - 입사 2014-10-02, 퇴사 2017-09-16, 재직일수 1,080일
   - 3개월 임금총액 7,080,000원 + 상여금가산액 1,000,000원 + 연차수당가산액 75,000원, 산정기간 총일수 92일
   - 공식 페이지에 명시된 1일 평균임금: **88,641원 31전**
   - ⚠️ **확인 필요**: 이 예시의 최종 퇴직금 금액은 원문 페이지에 명시되어 있지 않아 공식 계산기(labor.moel.go.kr/cmmt/calRtrmnt.do)에 동일 값을 직접 입력해 최종 퇴직금 결과를 재대조해야 한다. 위 UI breakdown 예시의 7,868,433원은 공식 산식으로 직접 계산한 값이며 공식 사이트에서 재확인된 값이 아니다.
2. **자체 구성 검증용 케이스(공식 대조 아님, 산식 정합성 확인용)**
   - 입사 2023-01-01, 퇴사 2024-01-01 (재직일수 365일), 제외기간 없음, 상여금/연차수당/통상임금 없음
   - 3개월(2023-10-01~2023-12-31, 92일) 임금총액 9,200,000원
   - 1일 평균임금 = 9,200,000 ÷ 92 = 100,000원(정확히 나누어떨어짐)
   - 퇴직금 = 100,000 × 30 × (365/365) = **3,000,000원**
   - ⚠️ 이 케이스는 "공식 계산기 예시값과 대조"라는 CLAUDE.md 요건을 충족하지 못한다. 구현 전 두 번째 공식 출처 예시를 추가로 찾거나, 위 1번 케이스를 공식 계산기에서 직접 검증해 대체해야 한다.
